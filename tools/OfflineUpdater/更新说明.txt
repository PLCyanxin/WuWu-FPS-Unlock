鸣潮 FPS Unlock v1.2RC 更新说明

【重要风险提示】使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

新增实验性 Dynamic 最大倍率，默认 4x，支持 0（NVIDIA 默认）、2x 至 6x。首次部署可在启动器中选择，后续可在游戏内 MFG Unlock 面板修改，完全退出并重新启动游戏后应用；本版不支持热切换。实际倍率仍由 NVIDIA 原生 Dynamic 调度，配置成功不等于游戏内上限已验证。更新后请打开启动器，在设置中重新部署一次。

以后如何更新
在设置中选择是否启动时自动检测，也可点击“检查更新”。发现新版时显示更新说明，选择立即更新、暂不更新，或跳过该版本。自动检测不等于自动安装，游戏运行时不能安装更新。下载校验通过后由独立更新器接手，更新后仍需重新部署。

如何更新
1. 正常退出游戏，再退出系统托盘中的启动器。
2. 右键桌面启动器快捷方式，选择“打开文件所在的位置”。
3. 把整个更新文件夹放进原启动器目录，双击“更新.exe”。请保留独立文件夹，不要把新协议包平铺混进原安装目录。
4. 更新器查找自身目录及最多三层上级目录中的主程序，找到唯一安装后，先备份再更新。不要直接运行 update-payload 内的主程序。
5. 更新完成后会刷新指向该安装的桌面快捷方式；没有找到就创建一个新的。
6. 打开启动器，在设置中重新部署一次，再进入游戏。

更新包适用于本项目 GitHub 和网盘发布的旧版本，不限定旧版本号或哈希；首次使用请下载完整版。
本版会更新启动器、FPS 核心与 MFG addon，其余 DLSS / Streamline 材料保留。
若提示被占用，请完全退出启动器；权限不足时，可右键更新器选择“以管理员身份运行”。

如何回退
1. 退出游戏，在启动器“设置”中点击“回退版本”。确认后启动器退出，由独立更新器恢复最近一次更新前的备份。
2. 也可完全退出启动器后，双击更新成功后生成的“回退.cmd”，或备份目录中的 rollback.cmd。
3. 回退成功后，这份备份不能再次回退；没有可用备份或已经回退时，“回退版本”按钮不可用。
4. 回退完成后，打开启动器，在设置中重新部署一次。

只保留最近一次更新前的完整备份。新备份校验完整且更新成功后，自动清除之前的有效备份；更新失败不会因此删除上一份备份。无法安全识别或清除的旧目录会保留并提示。
备份来自你更新前实际使用的软件，包含自行更换的组件，不是下载一个统一旧版。
配置和部署记录也会备份，但自动回退保留当前 data，以免丢失更新后重新部署的记录；更新与回退都不会直接写入游戏目录。

更新完成后可以删除更新文件夹。
想保留回退能力，请保留安装目录下本次生成的 update-backup-日期-编号 文件夹。
更新文件夹删除后，仍可进入该备份文件夹运行 rollback.cmd 回退。
