鸣潮 FPS Unlock v1.2.1RC 使用说明

【重要风险提示】使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

本版支持在游戏内实时调整 Dynamic 最大倍率，并自动保存所选上限。插件在首次使用时默认采用4x；如果您将上限改为6x，后续启动仍会使用6x，直到您再次修改。该功能仍为实验性功能。您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。NVIDIA 原生 Dynamic 会根据运行条件决定实际倍率。

当场景负载较高、基础渲染帧率较低时，Dynamic 可能提高生成倍率，以接近您设置的目标帧率。更高的生成倍率可能增加处理开销和延迟，让画面与操作之间产生黏滞感，影响游戏体验。您可以通过降低 Dynamic 最大倍率，限制过高的生成倍率，在输出帧率与操作响应之间取得平衡。降低上限后，实际输出帧率也可能下降。

相比 v1.2RC，本版支持在游戏内实时调整 Dynamic 倍率上限。您可以根据当前场景和操作感受随时调整，无需退出游戏；插件会自动保存您的选择，供后续启动继续使用。

使用方法
1. 请正常退出游戏，再退出系统托盘中的启动器。
2. 请右键桌面启动器快捷方式，选择“打开文件所在的位置”。
3. 请将解压后的整个独立更新文件夹放进原启动器目录，再运行其中的“更新.exe”。不要直接运行 update-payload 内的主程序。
4. 更新器会检查自身目录及最多三层上级目录中的主程序，找到唯一安装后，先备份您的现有文件，再执行更新。
5. 更新期间，请勿关闭更新窗口或游戏启动器，也不要启动游戏。更新器会自动完成必要的退出和重新打开操作。
6. 更新器会刷新指向该安装的桌面快捷方式；如果没有找到对应的快捷方式，它会创建一个新的。
7. 更新成功后，启动器会打开设置并提示“更新完成，请点击重新部署”。请点击“开始部署”，等待完成后再启动游戏。如果启动器未自动打开，请手动打开设置完成部署。

本更新包适用于本项目通过 GitHub 和网盘发布的旧版本。首次使用本工具时，请下载完整包。本更新包会替换启动器、FPS 核心和 MFG addon，并保留其他 DLSS / Streamline 材料。

如果更新器提示文件被占用，请完全退出启动器后重试。如果更新器提示权限不足，请按 Windows 的正常权限机制操作。

后续更新
您可以在设置中选择是否启用“启动时自动检查更新”，也可以手动点击“检查更新”。启动器发现正式新版后会展示更新说明，您可以立即更新、暂不更新、跳过该版本，或选择“本次游玩后帮我更新”。选择游玩后更新时，启动器会等待游戏退出，再恢复到前台并开始更新。主动退出启动器会取消本次预约。

“跳过这个版本”只关闭自动提醒，您仍可通过“检查更新”进入更新流程。游戏运行期间，启动器不会安装更新。无论您采用哪种更新方式，更新成功后都需要重新部署一次。

启动器只检查正式 Release。Pre-release 请在发布页手动下载。维护者验证版本稳定后，会将该版本从 Pre-release 转为 Release，供启动器检查和更新。

回退方法
1. 请退出游戏，在启动器设置中点击“回退版本”。您确认后，启动器会退出，由独立更新器恢复最近一次更新前的备份。
2. 您也可以完全退出启动器后，运行本次更新文件夹中的“回退.cmd”，或备份目录中的 rollback.cmd。
3. 回退完成后，请打开启动器，在设置中重新部署一次。

更新器备份的是您更新前实际使用的程序和组件，而非统一的历史发布包。每次成功更新后，更新器只保留最近一次更新前的有效备份，并清理可以安全识别的旧备份。更新失败时，更新器不会因此删除上一份备份。

回退会保留当前配置和部署记录，避免丢失更新后产生的部署信息。更新与回退都不会直接修改游戏文件。没有可用备份或已经完成回退时，“回退版本”按钮将不可点击。

更新完成后，您可以删除更新文件夹。如果您希望保留回退能力，请保留安装目录中的 update-backup-日期-编号 文件夹；您仍可通过其中的 rollback.cmd 回退。
