# 鸣潮 FPS Unlock

为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署。Windows 原生界面，开关与目标帧率集中在主窗口，组件管理放在设置中。

## v1.1.1RC 有什么新变化

- 更新多帧生成插件，可在游戏内的 MFG Unlock 面板查看 **Dynamic 当前实际生成倍率**。
- 新增部分实验性画面调优选项，可按需尝试，具体效果取决于游戏场景和设备。
- 更新包支持自动查找原安装目录，并在更新前备份用户自己的软件文件。
- 新增回退入口：恢复的是你更新前实际使用的程序与插件材料，包括自己替换过的 addon，而不是统一退回某个旧发布版。

## 第一次使用

1. 下载完整版，解压到一个固定文件夹，运行 `WuWaFpsUnlock.exe`。包内已包含所需运行时，无需另装 .NET。
2. 打开设置，点击“帮我查找鸣潮”，或手动选择游戏目录。确认游戏 EXE 指向 `Client\Binaries\Win64\Client-Win64-Shipping.exe`。
3. 开启“解锁帧率上限”，设定目标 FPS，然后点击“开始游戏”。只使用帧率解锁时，无需部署多帧生成组件。
4. 需要多帧生成时，在游戏关闭后开启“多帧生成部署”，点击“开始部署”，确认文件映射后等待完成，再启动游戏。

请保留完整程序目录，桌面上可以创建快捷方式，不要只移动主 EXE。

## 已有版本如何更新

GitHub、百度网盘分发的本项目旧版都可以使用更新包，不要求旧版本号或文件哈希相同。更新包需要已有安装；首次使用请选择完整版。

1. 正常退出游戏，再退出系统托盘中的启动器。
2. 下载并解压 `WuWaFPSUnlock-1.1.1RC-update.zip`。
3. 找到原启动器目录。若平时使用桌面快捷方式，可右键快捷方式，选择“打开文件所在的位置”。
4. 把解压后的**整个更新文件夹**放进原启动器目录，双击里面的 **`更新.exe`**。不用先覆盖主程序。
5. 确认更新窗口显示的安装目录正确，等待备份和更新完成。更新器会检查自身目录及最多三层上级目录中的主程序；找不到或出现多个安装时会提示原因。
6. 更新完成后会刷新当前用户桌面上指向该安装的快捷方式；没有找到时创建一个新的。
7. **打开启动器，进入设置，重新部署一次。** 更新包修改的是启动器与本地组件材料；重新部署后，新 addon 才会写入游戏目录。

推荐的放置方式：

```text
鸣潮 FPS Unlock/
├─ WuWaFpsUnlock.exe
├─ data/
├─ payload/
└─ 更新文件夹/
   ├─ 更新.exe          ← 双击这里
   └─ update-payload/
```

更新过程中不要启动游戏或旧启动器。若提示文件被占用，请从托盘完全退出后重试；若提示权限不足，可按 Windows 的正常方式以管理员身份运行更新器。

**更新成功后可以删除更新文件夹。** 用户备份独立保存在原安装目录的 `update-backup-日期-编号` 文件夹中；希望保留回退能力时，请不要删除这份备份。

## 对更新不满意，如何回退

更新成功后，更新文件夹中会出现 **`回退.cmd`**。

1. 退出游戏和托盘中的启动器。
2. 双击本次更新文件夹里的 `回退.cmd`，按提示恢复。
3. 如果更新文件夹已删除，进入原安装目录中对应的 `update-backup-日期-编号` 文件夹，运行其中的 **`rollback.cmd`**。
4. **回退完成后，打开启动器，在设置中重新部署一次**，让游戏使用恢复后的插件材料。

回退使用更新前在本机保存的文件，不会下载旧版本。程序与组件材料恢复为更新前的实际内容；配置和部署记录也有备份，但自动回退保留当前 `data`，以免丢失更新后重新部署产生的文件记录。后来新增的无关文件不会被批量删除。

回退不直接修改游戏文件，也不代替官方文件校验。请保留备份目录，直到确认不再需要恢复。

## 帧率、游戏启动与托盘

目标帧率可设为 **30–420 FPS**，开关和设置在下次启动游戏时生效。目标 FPS 不是实际帧率保证，实际表现取决于硬件、画质和场景。

帧率解锁由内置模块持续工作，游戏运行期间请让启动器留在托盘中。游戏启动后，启动器自动收起，按钮显示“游戏中”；游戏退出后，启动器自动关闭。双击托盘图标或桌面快捷方式可恢复窗口。

游戏运行时点击窗口的 × 会收起到托盘，没有游戏运行时则直接退出。点击“游戏中”会结束同一安装的现有游戏并重新启动，可能中断当前操作，请先保存进度。

## 多帧生成与 Dynamic

多帧生成与基础帧率解锁可分别使用。启用多帧生成部署选项后，启动器使用 DX12 启动游戏。Fixed 与 Dynamic 共用组件，无需安装两套包。

进入游戏后，在 ReShade 的 **MFG Unlock** 面板查看插件状态、Dynamic 实际生成倍率及调优选项。倍率显示反映插件观测到的运行状态，可能随场景变化；目标倍率和目标 FPS 不等于实际输出。

Dynamic 的驱动预检查门槛为 **595.41**，不是整个工具或 FPS 解锁功能的最低驱动要求。是否可用还取决于显卡、游戏、运行库和相关设置；驱动条件满足或部署完成，都不等于游戏内已生效。

实验性画面选项建议逐项尝试；遇到画面异常或稳定性问题，可关闭相应选项，并按插件面板提示重启游戏。它们不是所有设备都必须开启的优化。

## 组件维护与清除

启动器优先复用当前鸣潮安装中兼容的 ReShade。需要安装时使用随包安装器；升级已有 ReShade 前会提示。不会因为其他游戏装过 ReShade 就认为鸣潮也已安装。

自行更换 MFG addon 时，将文件放到 `payload/files/addon/renodx-mfgunlock.addon64`，然后关闭游戏，在设置中重新部署。工具允许更新本地材料，不要求 addon 与旧清单哈希一致。v1.1.1RC 更新包会替换这个 addon；其他自行维护的 DLSS/Streamline 材料不会随本次更新被换掉。

“清除插件”按部署记录处理本工具负责的文件。用户原有的 ReShade、滤镜和其他 addon 会保留，由本工具安装的 ReShade 按来源记录处理。清除不会恢复官方 DLL；之后可能需要在官方启动器中进行文件校验。**不要依赖普通启动自动补齐文件。**

如果提示游戏文件缺失，请先在官方启动器中修复，再回到本工具部署。配置、部署记录和日志位于 `data/`，迁移软件时请一并保留。

第三方插件可能因游戏更新发生不兼容、崩溃或账号风险，请自行评估后使用。本工具不保证所有游戏版本与设备组合均可使用。
