# 鸣潮 FPS Unlock

本工具为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署功能。工具采用 Windows 原生界面，主窗口提供帧率开关与目标帧率设置，设置窗口提供组件管理功能。

## Dynamic 运行时倍率上限

当场景负载较高、基础渲染帧率较低时，Dynamic 可能提高生成倍率，以接近您设置的目标帧率。更高的生成倍率可能增加处理开销和延迟，让画面与操作之间产生黏滞感，影响游戏体验。您可以通过降低 Dynamic 最大倍率，限制过高的生成倍率，在输出帧率与操作响应之间取得平衡。降低上限后，实际输出帧率也可能下降。

相比 v1.2RC，本版支持在游戏内实时调整 Dynamic 倍率上限。您可以根据当前场景和操作感受随时调整，无需退出游戏；插件会自动保存您的选择，供后续启动继续使用。


- 您可以在游戏内 ReShade 的 MFG Unlock 面板调整 Dynamic 最大倍率。首次使用时，插件默认请求 4x；此后，插件会沿用您保存的选择。
- 启动器不再提供部署时的静态倍率选项，旧的静态配置不再参与倍率控制；您需要在升级后重新部署组件，并完整重启一次游戏。
- 您可以在游戏运行时选择 2x–6x。您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。NVIDIA 原生 Dynamic 仍会根据负载与运行时能力决定实际倍率。
- 运行时调整倍率属于实验功能，插件仅支持随包适配的运行库。如果兼容性检测失败，插件会停用运行时控制并显示原因。您不应关闭安全软件来强行启用该功能。
- 您需要在更新后打开启动器设置，重新部署一次组件，让游戏使用新版插件。

## 第一次使用

1. 您需要下载完整版，将其解压到一个固定文件夹，然后运行 `WuWaFpsUnlock.exe`。完整包已包含所需运行时，您无需另装 .NET。
2. 您可以打开设置，点击“帮我查找鸣潮”，或手动选择游戏目录。请您确认游戏 EXE 指向 `Client\Binaries\Win64\Client-Win64-Shipping.exe`。
3. 您可以开启“解锁帧率上限”，设定目标 FPS，然后点击“开始游戏”。如果您只使用帧率解锁功能，就无需部署多帧生成组件。
4. 如果您需要多帧生成，请在游戏关闭后开启“多帧生成部署”，点击“开始部署”，确认文件映射后等待完成，再启动游戏。

您需要保留完整程序目录。您可以在桌面上创建快捷方式，但不要只移动主 EXE。

## 已有版本如何更新

### 在启动器中更新

从 v1.1.1 起，启动器设置提供“启动时自动检查更新”和“检查更新”。启动器默认开启自动检测，但只查询版本，不会自动下载或安装更新。网络异常不会影响您启动游戏；您关闭自动检测后，仍可手动检查更新。

检测到新版本时，窗口会展示版本号与更新说明。您选择“立即更新”后，启动器会下载并校验更新包；您选择“暂不更新”后，可以继续使用当前版本。您勾选“跳过这个版本”后，启动器不再自动提醒该版本，但仍会提示更高版本。您也可以通过手动检查重新查看被跳过的版本。更新检查只提供正式 Release，您需要在发布页手动下载 Pre-release。维护者验证版本稳定后，会将 Pre-release 设置为 Release，供启动器检测和更新。

您可以选择“本次游玩后帮我更新”，预约更新窗口所展示的版本。游戏运行期间，启动器不会下载或安装更新；游戏退出后，启动器会恢复到前台并开始更新。如果您尚未开始游戏，启动器会等待下一次由它启动的游戏结束后再更新。预约只在本次启动器会话内有效，您主动退出工具时，启动器会取消预约。如果下载被取消或失败，您可以点击“检查更新”重试。

“跳过这个版本”只影响自动提醒，您仍可通过手动“检查更新”完成更新。无论您选择立即更新、游玩后更新还是手动离线更新，更新器都会在更新成功后重新打开启动器，并弹出“更新完成，请点击重新部署”提醒。
游戏运行时，启动器不允许安装更新。您可以取消下载；校验通过后，启动器会退出，由独立更新器接手安装。**您仍需在更新后打开启动器，在设置中重新部署一次。**

### 使用离线更新包

GitHub、百度网盘分发的本项目旧版都可以使用更新包，不要求旧版本号或文件哈希相同。更新包需要配合已有安装使用；首次使用本工具的用户请选择完整版。

1. 您需要正常退出游戏，再退出系统托盘中的启动器。
2. 您需要下载并解压 `WuWaFPSUnlock-1.2.1RC-update.zip`。
3. 您需要找到原启动器目录。如果您平时使用桌面快捷方式，可以右键点击快捷方式，选择“打开文件所在的位置”。
4. 您需要把解压后的**整个更新文件夹**放进原启动器目录，双击里面的 **`更新.exe`**。请保留独立文件夹，不要把新协议包平铺混进原安装目录，也不用先覆盖主程序。
5. 您需要确认更新窗口显示的安装目录正确，然后等待备份和更新完成。更新器会检查自身目录及最多三层上级目录中的主程序；找不到或出现多个安装时会提示原因。
6. 更新器会在更新完成后刷新当前用户桌面上指向该安装的快捷方式；如果没有找到匹配的快捷方式，更新器会创建一个新的快捷方式。
7. **您需要打开启动器，进入设置，重新部署一次。** 更新包修改的是启动器与本地组件材料；启动器只有在重新部署后，才会将新 addon 写入游戏目录。

推荐的放置方式：

```text
鸣潮 FPS Unlock/
├─ WuWaFpsUnlock.exe
├─ data/
├─ payload/
└─ 更新文件夹/
   ├─ 更新.exe          ← 双击这里
   └─ update-payload/
```

您在更新过程中不要启动游戏或旧启动器。如果更新器提示文件被占用，请您从托盘完全退出启动器后重试；如果更新器提示权限不足，您可以按 Windows 的正常方式以管理员身份运行更新器。

**您可以在更新成功后删除更新文件夹。** 用户备份独立保存在原安装目录的 `update-backup-日期-编号` 文件夹中；希望保留回退能力时，请不要删除这份备份。

## 对更新不满意，如何回退

1. 您需要正常退出游戏，然后打开启动器设置。
2. 您可以在“部署与维护”中选择 **回退版本**，确认操作后等待启动器退出。更新器随后会恢复备份中的程序文件。
3. **您需要在回退完成后打开启动器，在设置中重新部署一次**，让游戏使用恢复后的插件材料。

如果没有可用备份或已经完成回退，启动器会禁用“回退版本”按钮。每次成功更新后，更新器只保留最近一次更新前的可管理备份；更新器验证新备份并成功完成更新后，会清理旧备份。如果备份中存在无法识别或被修改的文件，更新器会保留这些备份并提示原因，不会强行删除它们。

您也可以在退出启动器后，运行本次更新文件夹里的 **回退.cmd**。如果您已经删除更新文件夹，可以运行备份文件夹内的 **rollback.cmd**。
回退使用更新前在本机保存的文件，不会下载旧版本。回退会将程序与组件材料恢复为更新前的实际内容。备份也包含配置和部署记录，但自动回退会保留当前 `data`，以免丢失更新后重新部署产生的文件记录。更新器不会批量删除您后来新增的无关文件。

回退不直接修改游戏文件，也不代替官方文件校验。请保留备份目录，直到确认不再需要恢复。

## 帧率、游戏启动与托盘

您可以将目标帧率设置为 **30–420 FPS**。帧率开关和目标值会在下次启动游戏时生效。目标 FPS 不保证游戏能够达到对应帧率，实际表现取决于硬件、画质和场景。

内置模块会持续执行帧率解锁，您需要在游戏运行期间让启动器留在托盘中。游戏启动后，启动器会自动收起，“开始游戏”按钮会显示“游戏中”。如果您没有预约更新，启动器会在游戏退出后自动关闭；如果您已经预约更新，启动器会恢复到前台并开始更新。您可以双击托盘图标或桌面快捷方式来恢复窗口。

游戏运行时，您点击窗口的 × 后，启动器会收起到托盘；没有游戏运行时，启动器会直接退出。您点击“游戏中”后，启动器会结束同一安装的现有游戏并重新启动。这项操作可能中断当前操作，请先保存进度。

## 多帧生成与 Dynamic

您可以分别使用多帧生成与基础帧率解锁功能。您启用多帧生成部署选项后，启动器会使用 DX12 启动游戏。Fixed 与 Dynamic 共用组件，您无需安装两套包。

您进入游戏后，可以在 ReShade 的 **MFG Unlock** 面板查看插件状态、Dynamic 实际生成倍率及调优选项。倍率显示反映插件观测到的运行状态，可能随场景变化；目标倍率和目标 FPS 不等于实际输出。

Dynamic 的驱动预检查门槛为 **595.41**，不是整个工具或 FPS 解锁功能的最低驱动要求。Dynamic 是否可用还取决于显卡、游戏、运行库和相关设置。驱动条件满足或组件部署完成，都不代表 Dynamic 已在游戏内生效。

**Dynamic 最大倍率属于实验性功能，首次使用时默认请求 4x。** 您可以在游戏内 ReShade 的 **MFG Unlock → Dynamic maximum multiplier** 中选择 2x–6x，插件会在运行时应用该选择。您也可以选择 Native bound (restore)，让插件恢复原生上限。插件会自动保存您的选择，并在后续启动时继续使用，直到您再次修改。此功能只影响 Dynamic，不改变 Fixed。

您需要在更新后退出游戏、重新部署组件，并完整启动一次游戏。此后，您调整最大倍率时无需重启游戏，也无需重新部署组件。启动器不再提供部署时的倍率选项。
实际倍率和兼容性取决于设备、驱动、运行库与场景。您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。游戏不一定会达到该倍率，您也不能仅凭设置保存成功就判断限制已经生效。详细说明请参阅 [Dynamic 最大倍率说明](docs/DYNAMIC_MAX_MULTIPLIER.md)。

建议您逐项尝试实验性画面选项。如果您遇到画面异常或稳定性问题，可以关闭相应选项，并按插件面板提示重启游戏。这些选项并非所有设备都必须开启的优化。

## 组件维护与清除

启动器优先复用当前鸣潮安装中兼容的 ReShade。如果当前安装需要 ReShade，启动器会使用随包安装器进行安装；如果需要升级已有的 ReShade，启动器会先提示您。启动器不会因为其他游戏装过 ReShade，就认为鸣潮也已安装 ReShade。

如果您需要自行更换 MFG addon，可以将文件放到 `payload/files/addon/renodx-mfgunlock.addon64`，然后关闭游戏，在设置中重新部署。工具允许更新本地材料，不要求 addon 与旧清单哈希一致。本版更新包会替换这个 addon；其他自行维护的 DLSS/Streamline 材料不会随本次更新被换掉。

您使用“清除插件”时，启动器会按部署记录处理本工具负责的文件。启动器会保留用户原有的 ReShade、滤镜和其他 addon，并按来源记录处理由本工具安装的 ReShade。清除操作不会恢复官方 DLL；您之后可能需要在官方启动器中进行文件校验。**不要依赖普通启动自动补齐文件。**

如果启动器提示游戏文件缺失，您需要先在官方启动器中修复文件，再回到本工具部署组件。配置、部署记录和日志位于 `data/`，迁移软件时请一并保留。

第三方插件可能因游戏更新发生不兼容、崩溃或账号风险，请自行评估后使用。本工具不保证所有游戏版本与设备组合均可使用。

```powershell

```

源码构建不包含完整的第三方材料包；普通用户请下载 Release 完整版。第三方组件保持各自的版本与许可，您可以参阅 [第三方说明](licenses/THIRD_PARTY_NOTICES.md)。
