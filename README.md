## 安装与首次使用

### 使用前准备

使用 Windows x64，并先确认鸣潮能够通过官方启动器正常启动。完整包包含所需的 .NET 运行时，无需另行安装 .NET。

帧率解锁和多帧生成相互独立。仅使用帧率解锁时，无需部署多帧生成组件，也不受 Dynamic 驱动门槛限制。多帧生成需要兼容的显卡、驱动及运行库，并使用 **DX12** 启动；本工具会以 DX12 启动所选游戏。Dynamic 的驱动预检查门槛为 **595.41**，达到门槛仍需满足游戏内运行库的兼容性条件。

### 下载与解压

在发布页下载以 **win-x64.zip** 结尾的完整包，解压到固定文件夹，运行 **WuWaFpsUnlock.exe**。请保留完整目录，不要单独移动主 EXE；需要从桌面启动时，请创建快捷方式。

以 **update.zip** 结尾的文件用于更新已有完整安装，首次安装请勿选用。收到 RAR 分发包时，同样需要完整解压；本项目 RAR 包的解压密码为 **yanxin**。

### 首次使用步骤

1. 在“设置”中选择鸣潮安装目录，或点击 **帮我查找鸣潮**，确认关联的游戏 EXE 正确。
2. 在主页 **包体档位** 菜单中选择已通过官方启动器下载并安装的档位。
3. 如需帧率解锁，开启 **解锁帧率上限**并设置目标 FPS；不需要时保持关闭。
4. 如需多帧生成，先退出游戏，在设置中开启 **多帧生成部署**，点击 **开始部署**，核对文件计划并确认。
5. 点击 **开始游戏**。新的部署首次启动会显示风险与须知；确认后保存本次部署的确认状态，日常启动不重复提示。取消时不会结束现有游戏或启动新实例。
6. 使用多帧生成时，进入游戏后按菜单按键（默认 **Home**）打开 ReShade，在 **MFG Unlock** 中选择帧生成模式及对应设置。

只使用帧率解锁时可以跳过第 4、6 步；只使用多帧生成时无需开启帧率解锁。

## 游戏路径

打开“设置”，可通过 **浏览**选择官方启动器目录或游戏根目录，也可通过 **选择**指定真正的游戏 EXE。选择目录后，工具会查找对应的游戏 EXE；选择游戏 EXE 后，会关联其所属的游戏目录。

正确的游戏 EXE 在所选游戏根目录中的相对位置为：

```text
Client\Binaries\Win64\Client-Win64-Shipping.exe
```

请勿选择官方启动器、崩溃报告程序或本工具。**帮我查找鸣潮**只在点击后执行一次查找，不会持续扫描电脑。

如果提示游戏文件缺失，请先通过官方启动器校验和修复，并启动一次游戏，确认能够正常运行后再部署。官方更新改变文件位置后，如仍提示记录中的旧路径缺失，可在提示中核对路径记录重建计划，确认新的文件位置后再部署。重建只更新本工具的记录，不复制或删除游戏文件。

<a id="fps-unlock"></a>
## 帧率解锁

在主页开启 **解锁帧率上限**，通过数值框或滑块设置 **30–420 FPS** 目标，再点击 **开始游戏**。内置模块会在游戏运行期间持续维持设置，请让启动器留在托盘运行。模块会确认目标值的写入结果；遇到暂时无法访问的设置时，保留会话，并在原设置恢复可用后自动继续维持。启动器日志会记录模块状态，便于排查帧率解锁问题。

**帧率开关和目标值在下一次通过本工具启动游戏时生效。**“解锁帧率上限”不会向您的游戏文件夹部署插件，开启、关闭或修改目标均无需重新部署。关闭后启动游戏，不加载帧率解锁模块，也不会卸载已经部署的多帧生成组件。

目标 FPS 是设置值，实际帧率取决于硬件、画质、场景负载和其他限帧设置。它与 Dynamic 的“目标输出帧率”相互独立，不代表相同的运行数据。

<a id="deployment"></a>
## 一键部署多帧生成

1. 正常退出鸣潮。
2. 打开设置，确认游戏目录与 EXE 正确，并开启 **多帧生成部署**。
3. 点击 **开始部署**，查看将要处理的文件、ReShade 来源及配置计划。
4. 核对计划并确认，等待部署完成后通过本工具启动游戏。

工具优先复用所选鸣潮安装中兼容的 ReShade。需要安装时使用随包材料；需要升级已有版本时会提示。固定帧生成（Fixed）与 Dynamic 共用组件，无需安装两套包。

**多帧生成部署**开关决定下一次部署的内容，关闭它不会卸载已经安装的插件。需要移除组件时，请使用[清除插件](#cleanup)。部署和清除均应在游戏退出后进行。

更新启动器或组件后，需要重新部署，游戏才会使用相应插件。驱动条件满足、部署完成均不等于游戏内功能已经生效，实际状态请在游戏内菜单中查看。

<a id="frame-generation"></a>
## 游戏内帧生成设置

进入游戏后，按菜单按键（默认 **Home**）打开 ReShade，选择 **MFG Unlock**。随包插件基于上游 MFG Unlock 1.3.0，菜单已完成汉化。

### 选择帧生成模式

| 模式 | 用法 |
| --- | --- |
| **固定倍率（Fixed）** | 显示“固定帧生成倍率”，可选择 2x–6x |
| **Dynamic** | 显示 Dynamic 设置，可调整最大倍率和目标输出帧率 |
| **游戏默认** | 撤销自定义倍率覆盖，由游戏自身设置决定是否启用帧生成及其倍率；不显示倍率子菜单 |
| **关闭** | 停用帧生成，不显示倍率子菜单；需要对应运行库的控制能力可用 |

选择模式后，只显示该模式的派生设置，无需再勾选重复的开启开关。**游戏默认不等于关闭帧生成。** 如需关闭，请在“帧生成模式”中选择“关闭”。这将便于您在凹分时关闭帧生成，避免帧生成带来的额外延迟。

模式、固定倍率与 Dynamic 上限会分别保存。选择“关闭”不会清空已经保存的倍率；再次选择 Fixed 或 Dynamic 时，继续使用该模式上次的有效设置。首次使用的自定义倍率为 **4x**。

在兼容的运行库上，可以在游戏运行期间修改设置，无需为每次调整重新部署或重启。设置在后续帧生成处理时应用；游戏暂停或暂时没有相应提交时，画面状态可能不会立即变化。兼容性检查未通过时，相关运行时控制不可用，请查看菜单提示。

<a id="dynamic-maximum"></a>
### Dynamic 最大倍率

在 Dynamic 模式下，将 **Dynamic 最大倍率**设为最高 **2x–6x**，或选择 **跟随原生上限**取消自定义限制。首次使用默认最高 **4x**；选择自动保存，后续启动继续使用，直到再次修改。请确保 ReShade 配置文件可写。

在复杂场景中，原始帧率较低时，Dynamic 可能提高生成倍率以接近目标帧率。较高倍率可能增加处理开销和延迟，让操作响应显得黏滞。此时可以降低最大倍率，在输出帧率和操作手感之间取得平衡；降低上限也可能降低实际输出帧率。

**Dynamic 最大倍率仍属于实验性功能。** 您选择的是允许使用的倍率上限，而不是固定输出倍率。NVIDIA 原生 Dynamic 会根据负载、硬件、驱动和运行库能力决定实际倍率，不保证达到所选上限。

### Dynamic 目标输出帧率

Dynamic 的“目标输出帧率”用于设置期望的最终输出帧率。设为 **0** 时跟随显示器刷新率；此处的 0 不表示关闭帧生成。

> [!IMPORTANT]
> **使用 Dynamic 自定义“目标输出帧率”前，请关闭游戏内和 NVIDIA 驱动中的垂直同步（VSync），并检查 G-SYNC 等显示同步设置。VSync 生效时，Dynamic 会跟随显示器当前启用的刷新率，忽略自定义目标输出帧率。** 单独开启 G-SYNC 不等于启用 VSync；当前刷新率也不一定是显示器支持的最大刷新率。

### 倍率状态与其他选项

菜单中的倍率状态显示为 **关闭、1x–6x 或未捕获**，反映插件捕获的运行状态。“未捕获”表示当前没有有效数据，不能据此直接判断帧生成是否生效；所选倍率、实际倍率和 FPS 计数也不是同一项数据。

菜单还提供画面调优选项。建议逐项调整，出现画面异常时关闭对应选项；需要重启的设置以菜单提示为准，无需开启所有实验选项。

ReShade 菜单使用系统光标，指针刷新可跟随桌面刷新率；菜单内容随游戏渲染刷新。拖动标题栏可移动菜单，按住 **Shift** 拖动可调整停靠位置。

<a id="game-launch"></a>
## 游戏启动与包体档位

在主页点击 **包体档位**，选择极致、高清或流畅，再点击 **开始游戏**。档位选择会自动保存，在下一次启动游戏时生效，**无需重新部署插件**。游戏运行期间更改档位不会切换已经加载的资源。

| 状态 | 含义与操作 |
| --- | --- |
| 🟢 已下载 | 找到该档位的官方下载完成记录；请确认官方启动器已完成安装 |
| 🔴 未下载 | 尚未找到该档位的下载完成记录，请先在官方启动器中下载并安装 |
| 🟡 下载中 | 检测到该档位正在写入下载资源，请等待官方启动器完成 |
| 未捕获 | 无法读取有效状态，请在官方启动器中确认资源情况 |

工具启动时检测状态，展开包体菜单后持续刷新。下载活动提示与官方下载记录不等于完整的游戏文件校验；暂停或结束下载后，黄色状态会在短暂等待后消退。

包体资源的下载、安装和切换由官方启动器完成。本工具只选择启动档位，不会代为下载、转换或补齐资源。

<a id="tray"></a>
### 托盘与重新启动

游戏启动后，启动器自动收起到通知区，“开始游戏”显示为“游戏中”。双击托盘图标或桌面快捷方式，可以恢复已有窗口；工具采用单实例运行，不会因此再打开第二个启动器。

| 操作或状态 | 启动器行为 |
| --- | --- |
| 游戏运行时点击窗口 × | 收起到托盘 |
| 没有游戏运行时点击窗口 × | 退出启动器 |
| 游戏退出，未预约更新 | 自动退出启动器 |
| 游戏退出，已预约更新 | 恢复到前台并开始更新 |
| 游戏运行时点击“游戏中” | 结束同一安装的现有游戏，等待退出后重新启动 |

**重新启动会直接结束同一安装的现有游戏，可能中断当前操作或丢失尚未保存的状态。** 工具按完整可执行文件路径识别游戏，无法确认归属或结束失败时，不会继续启动新实例。

<a id="environment"></a>
## 环境信息与菜单按键

设置页显示显卡型号、驱动版本、Windows 和 HAGS 状态。点击 **重新检测**可刷新信息；检测不会自动修改 HAGS、驱动或其他系统设置。ReShade 的安装和兼容性状态会在部署计划及日志中提示。

启动器在后台会减少重复扫描和空闲处理。在能够识别并使用 E 核的 Intel 混合架构处理器上，后台空闲任务优先使用 E 核，前台及关键操作恢复原处理器范围，不限制游戏进程。

<a id="menu-key"></a>
### 自定义菜单按键

**菜单按键**首次使用默认为 **Home**。点击按键框后，按下所需的单键或组合键即可保存，例如 **Ctrl + Alt + F1**；按 **Esc** 取消录入。

点击右侧 **×** 会清空绑定并显示“未设置”，此时游戏内菜单快捷键停用。需要恢复默认时，点击按键框并重新按下 **Home**。

修改会在重新部署或下一次通过本工具启动游戏时应用，不会立即改变正在运行的游戏。已自定义时，请用所设按键打开 ReShade。

<a id="official-download"></a>
## 大版本预下载与后续下载提醒

保存游戏路径后，每次打开工具，都会在后台检查所选安装是否有可用的大版本预下载。检测到尚未完成的预下载时，在确认游戏已停止且能找到对应官方启动器的情况下，打开官方启动器并提示下载。游戏包由官方启动器下载，本工具不会代为下载或安装。

预下载阶段已有官方下载完成记录时，不重复提醒。版本正式开放后，若本机仍未完成安装，会另行提示通过官方启动器完成后续补充下载与安装。

弹窗中可勾选 **不再提醒此预下载版本**，下次打开工具时，不再为该版本弹窗或打开官方启动器；新版本开放预下载时仍会提醒。

检查只针对大版本预下载及其正式开放后的后续更新，不提示其他普通游戏更新或官方启动器自身升级。网络异常、路径无法识别时，不阻止正常启动游戏；正在游戏或执行部署等操作时，不自动打开官方启动器。

## 软件更新

> [!IMPORTANT]
> **更新包从 GitHub 下载，受网络环境影响，可能出现下载缓慢或中断。遇到此类情况，建议开启支持 GitHub 加速的加速器，然后重新尝试更新。**

### 在线更新

在设置的“部署与维护”中，可选择是否开启 **启动时自动检查更新**，也可点击 **检查更新**。检测只提供正式 Release，不包含 Pre-release；自动检查只查询版本，不会未经选择直接安装，网络异常也不影响正常启动游戏。

检测到正式新版时，窗口显示版本号和更新说明，并提供以下操作：

| 操作 | 作用 |
| --- | --- |
| **立即更新** | 下载并校验更新包，再交由更新器安装；下载期间可以取消 |
| **暂不更新** | 保持当前版本，稍后再处理 |
| **跳过这个版本** | 关闭该版本的自动提醒；手动“检查更新”仍可重新查看并更新 |
| **本次游玩后帮我更新** | 等待本次游戏结束，自动下载并更新启动器；尚未开始游戏时，等待下一次由本工具启动的游戏结束 |

游戏运行期间不会安装更新。已预约更新时，游戏结束后启动器会恢复到前台继续更新，不按通常流程自动退出。主动退出启动器会取消预约；下载取消或失败后可手动重试。

### 离线更新

本项目已有的完整安装均可使用离线更新包，不要求旧文件与某个固定发布版本完全一致。

1. 正常退出游戏，并从托盘完全退出启动器。
2. 下载以 **update.zip** 结尾的更新包并完整解压；使用 RAR 更新包时，同样需要完整解压。
3. 找到原启动器目录。使用桌面快捷方式时，可右键选择“打开文件所在的位置”。
4. 将解压后的**整个独立更新文件夹**放入原启动器目录，运行其中的 **更新.exe**。
5. 核对更新窗口显示的安装目录，等待备份和更新完成。
6. 打开新版启动器设置，点击 **开始部署**，完成后再启动游戏。

```text
鸣潮 FPS Unlock/
├─ WuWaFpsUnlock.exe
├─ data/
├─ payload/
└─ 更新文件夹/
   ├─ 更新.exe           ← 运行此文件
   └─ update-payload/
```

请勿只复制更新器，也不要运行 `update-payload` 中的程序。更新器会刷新或创建对应的桌面快捷方式，并重新打开新版启动器。遇到占用提示时，请完全退出相关程序；权限请求按 Windows 的正常机制处理。

离线更新开始前，请先退出旧启动器。**开始更新后，请勿关闭更新窗口与游戏启动器，也不要启动游戏。** 后续退出与重新打开由更新器自动完成。

**无论采用哪种方式，更新完成后都会提示“更新完成，请点击重新部署”。** 更新包替换启动器及组件材料，重新部署后游戏才会使用相应插件。

更新成功后可以删除更新文件夹。需要保留回退能力时，请保留安装目录中的备份文件夹。

<a id="rollback"></a>
## 备份与回退

更新前，工具会备份本机实际使用的程序与组件。回退恢复的是这份备份，不是固定的上一发布版本。每次成功更新后，保留最近一次有效备份，并清理能安全识别的旧备份；无法识别或包含额外用户文件的目录会保留。

1. 正常退出游戏，打开启动器设置。
2. 在“部署与维护”中点击 **回退版本**，确认后等待恢复完成。
3. 重新打开启动器，**重新部署一次**，再启动游戏。

没有可用备份、已经回退或游戏仍在运行时，按钮不可点击。也可在退出启动器后，运行更新文件夹中的 **回退.cmd**，或备份文件夹中的 **rollback.cmd**。

回退恢复旧程序与组件材料，保留当前配置和部署记录，不直接修改游戏文件。请勿删除 `update-backup-日期-编号` 备份文件夹，除非已不再需要回退。

如果更新中断，请保持游戏和启动器关闭，重新运行同一更新包，或使用备份内的 **恢复.cmd**完成恢复。遇到文件被外部修改、备份损坏等提示时，请保留相关文件和日志，按提示处理，不要手动混用不同版本的程序文件。

<a id="cleanup"></a>
## 一键清除与配置保留

退出游戏后，在设置中点击 **清除插件**，核对提示并确认。工具按部署记录及可核对的文件来源清理负责的组件，保留用户原有的 ReShade、滤镜和其他插件；被其他工具修改过、无法确认来源的文件会保留并提示。

清除不会恢复官方 DLL，之后可能需要通过官方启动器校验和修复。**不要依赖普通启动自动补齐文件。**

配置、部署记录和日志保存在 `data/`。移动或备份软件时，请保留完整目录，避免丢失文件来源与清理记录。菜单按键等用户偏好不会因清除插件而重置。

<a id="diagnostic-logs"></a>
## 日志查看与导出

设置页的“运行日志”记录启动、环境检测、部署、清除及更新等操作。点击 **导出日志**，选择保存位置，即可导出用于排查问题的 TXT 文件，包含启动器诊断信息、操作日志及所选游戏的 ReShade 日志。

导出包含当前会话、最近两份启动器日志，以及存在的启动期异常日志。每份日志最多读取末尾 16 MiB，超出时会说明截取范围。

未找到 ReShade 日志时，导出文件会标注 **暂无 ReShade 日志**；文件无法读取时会说明原因，不会把它当作不存在。点击 **清空日志**可清空界面与当前会话日志，历史日志仍会保留。

反馈问题时，请提供工具版本、操作步骤及导出的日志。分享截图或日志前，请遮挡 UID 和其他个人信息。

## 常见问题

### 可以不使用帧率解锁，只使用多帧生成吗？

可以。关闭“解锁帧率上限”，在设置中开启“多帧生成部署”并完成部署，然后通过本工具启动游戏即可。两项功能可以分别使用。

### 开启或关闭“解锁帧率上限”需要重新部署吗？

不需要。该开关不会向您的游戏文件夹部署插件，切换开关或修改目标 FPS 后，在下一次通过本工具启动游戏时生效。多帧生成组件的部署与它相互独立。

### 可以切换 DLSS 模型吗？

可以。在 NVIDIA App 中找到鸣潮的程序设置，通过可用的 DLSS 模型覆盖选项调整。具体可选项取决于显卡、驱动和 NVIDIA App 版本。

### 为什么多帧生成不生效？

先确认已完成部署，并通过本工具以 DX12 启动游戏。然后在 NVIDIA App 中检查鸣潮的程序设置；如果调整过帧生成覆盖，请将对应选项恢复为 **使用 3D 应用程序设置**，避免覆盖游戏和插件配置。不同版本的选项名称可能略有不同。

更新组件后，需要完整退出游戏、重新部署，再启动游戏。Dynamic 还需满足运行库兼容性条件，请查看游戏内菜单的状态提示。

### 为什么设为 160 FPS，实际帧率仍更低？

目标值不保证实际性能。确认修改后已重新启动游戏，再检查画质、场景负载及其他限帧设置。帧率解锁目标、Dynamic 目标输出帧率与计数器显示值是不同的数据。

### 为什么更新后还是旧菜单，或找不到倍率选项？

先完整退出游戏，在新版启动器设置中重新部署，再启动游戏。已加载的插件不会随启动器更新而更换。

固定倍率（Fixed）与 Dynamic 各自只显示对应的派生设置，游戏默认和关闭不显示倍率子菜单；控件不可用时，请查看运行库兼容性提示。

### 菜单按键被清空后，怎么恢复？

在设置的“菜单按键”中点击按键框并按下 Home，或重新录入所需按键。修改会在重新部署或下一次启动游戏时应用。

### 为什么“检查更新”没有显示 Pre-release？

自动检查和手动检查均只提供正式 Release。Pre-release 请在 GitHub 发布页手动下载，已有安装可使用对应的离线更新包。

### 部署提示文件缺失，或清除后游戏无法启动怎么办？

如果缺失的是**游戏文件**，请先通过官方启动器进行文件校验和修复，确认游戏正常启动后再部署。

如果缺失的是**启动器部署清单或组件材料**，请重新下载并完整解压完整版，保留 `payload`、`components` 和其他随包目录。不要到游戏目录寻找 `manifest.json`，它属于启动器的部署材料。更新包不能代替完整安装，也不能补齐缺失的全部运行库。
