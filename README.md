# 鸣潮 FPS Unlock

为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署。主窗口用于设置目标帧率和启动游戏，设置窗口负责游戏路径、环境检测、组件维护与软件更新。

> [!IMPORTANT]
> **目前仅支持通过鸣潮官方启动器安装的游戏版本。未来不计划扩大支持范围，其他启动器或渠道版本不在支持范围内。**

## 主要功能

- **帧率解锁：** 支持设置 30–420 FPS 目标，实际帧率取决于硬件、画质和场景。
- **多帧生成：** 支持固定倍率与 NVIDIA Dynamic 两种模式，按设备和运行库能力使用。
- **游戏内倍率调整：** 调整固定帧生成倍率或 Dynamic 最大倍率，两种模式均可选择关闭帧生成。

## 产品特色

- **中文菜单：** 由本项目完成多帧生成菜单汉化，方便查看状态与调整选项。
- **Dynamic 上限实时调整：** 无需退出游戏即可修改上限，选择会自动保存，后续启动继续使用。该功能仍属实验性功能。
- **便捷更新：** 支持检测正式新版，也可预约在本次游玩结束后自动更新启动器。
- **可回退：** 更新前备份本机实际使用的版本，不满意时可恢复更新前的程序与组件。

## 使用前准备

- 使用 Windows x64，并先确认鸣潮可以通过官方启动器正常启动。
- 完整包包含所需的 .NET 运行时，无需另行安装 .NET。
- 帧率解锁和多帧生成可以分别使用。仅使用帧率解锁，无需部署多帧生成，也不受 Dynamic 驱动门槛限制。
- 多帧生成需要兼容的 NVIDIA 显卡、驱动和运行库，并使用 **DX12** 启动。Dynamic 的驱动预检查门槛为 **595.41**；达到门槛不代表所有硬件和游戏环境都能启用该功能。
- 目标 FPS 与所选倍率均不保证实际输出。游戏版本、场景、画质和硬件负载都会影响效果。

## 首次安装与启动

### 1. 下载完整包

在发布页选择以 **win-x64.zip** 结尾的完整包，解压到固定文件夹，运行 **WuWaFpsUnlock.exe**。

请保留完整目录，不要单独移动主 EXE。需要从桌面启动时，请创建快捷方式。首次安装不要下载 update.zip，它需要配合已有安装使用。

### 2. 选择鸣潮

打开“设置”，点击 **帮我查找鸣潮**，或手动选择游戏目录。自动查找由按钮触发，不会持续扫描电脑。

确认游戏 EXE 指向所选安装中的：

```text
Client\Binaries\Win64\Client-Win64-Shipping.exe
```

不要选择官方启动器、崩溃报告程序或本工具。如果提示游戏文件缺失，请先使用官方启动器修复文件，并启动一次游戏，再回来部署。

### 3. 选择需要的功能

**只使用帧率解锁：** 开启“解锁帧率上限”，设置目标 FPS，点击“开始游戏”即可，无需部署多帧生成组件。

**同时使用多帧生成：** 先退出游戏，在设置中开启“多帧生成部署”，点击 **开始部署**，核对文件计划并确认。完成后通过本工具启动游戏，再按 Home 打开游戏内菜单。

成功部署后，首次开始游戏会显示风险与须知。确认后会保存本次部署的确认状态，日常启动不重复提示；取消时不会结束现有游戏或启动新实例。

## 日常启动与托盘

帧率开关和目标值在**下一次启动游戏时生效**。关闭帧率解锁后启动游戏，不加载 FPS 模块；该开关不会卸载已经部署的多帧生成组件。

游戏启动后，启动器自动收起到通知区，“开始游戏”显示为“游戏中”。游戏运行期间让启动器留在托盘即可。双击托盘图标或桌面快捷方式可以恢复已有窗口。

| 操作或状态 | 启动器行为 |
| --- | --- |
| 游戏运行时点击窗口 × | 收起到托盘 |
| 没有游戏运行时点击窗口 × | 退出启动器 |
| 游戏退出，未预约更新 | 自动退出启动器 |
| 游戏退出，已预约更新 | 恢复到前台并开始更新 |
| 游戏运行时点击“游戏中” | 结束同一安装的现有游戏，等待退出后重新启动 |

**重新启动会直接结束同一安装的现有游戏，可能中断当前操作或丢失尚未保存的状态。** 工具按完整可执行文件路径识别游戏，无法确认归属或结束失败时不会继续启动新实例。

## 游戏内多帧生成设置

进入游戏后，按 **Home** 打开 ReShade，选择 **MFG Unlock**。随包插件基于上游 MFG Unlock 1.1.5，由本项目完成菜单汉化。

### 固定帧生成与 Dynamic

| 设置 | 作用 |
| --- | --- |
| 固定帧生成倍率 | 在固定模式下选择倍率，或选择“关闭” |
| NVIDIA Dynamic MFG | 切换是否使用 NVIDIA 原生 Dynamic 调度 |
| 启用 Dynamic 最大倍率限制 | 决定是否使用自定义 Dynamic 上限控制 |
| Dynamic 最大倍率 | 选择最高 2x–6x、“恢复原生上限”或“关闭” |

开启 Dynamic 后，固定帧生成倍率选项不可调节；关闭 Dynamic 后，Dynamic 最大倍率控件不可调节，但会保留已保存的选择。

两种模式的“关闭”选项独立保存，不会覆盖另一种模式的选择。这将便于您在凹分时关闭帧生成，避免帧生成带来的额外延迟。恢复时，选择当前模式所需的倍率即可。

**取消勾选“启用 Dynamic 最大倍率限制”仅停止自定义上限控制，不等于关闭帧生成。** 要在 Dynamic 模式下关闭帧生成，请在启用该控制时选择“关闭”。

### Dynamic 最大倍率如何使用

Dynamic 最大倍率支持在游戏内调整，无需为每次调整重新部署或重启。首次使用默认最高 **4x**，选择会自动保存，后续启动继续使用，直到再次修改。请确保 ReShade 配置文件可写。

在复杂场景中，Dynamic 可能提高生成倍率以接近目标帧率。较高倍率可能增加处理开销与延迟；如果感觉操作黏滞，可以尝试降低上限，在输出帧率和操作响应之间取得平衡。降低上限也可能降低实际输出帧率。

**Dynamic 最大倍率仍属于实验性功能。** 所选数值是上限，不是固定输出倍率；实际倍率由 NVIDIA 原生 Dynamic 根据负载、硬件、驱动及运行库能力决定。兼容性检查未通过时不会启用运行时控制。

### 状态与画面选项

倍率状态显示为 **关闭、1x–6x 或未捕获**。它反映插件获得的运行状态，不是显示器 FPS 计数；“未捕获”表示当前没有有效数据，不能据此直接判断帧生成是否生效。

菜单还提供画面调优选项。建议逐项调整，出现画面异常时关闭对应选项；需要重启的设置以菜单提示为准，不必把所有实验选项都打开。

Home 菜单使用系统光标，指针刷新可跟随桌面刷新率；菜单内容仍随游戏渲染刷新。拖动标题栏可以移动菜单，按住 **Shift** 拖动可以调整停靠位置。

## 设置与组件维护

### 环境信息

设置页显示显卡、驱动版本、Windows、HAGS 和 ReShade 状态，可点击 **重新检测** 刷新。检测不会自动修改 HAGS、驱动或系统设置；驱动条件满足与组件部署完成都不等于游戏内功能已经生效。

启动器会减少重复扫描和空闲处理。在能够识别并使用 E 核的 Intel 混合架构处理器上，后台空闲任务优先使用 E 核，前台及关键操作恢复原处理器范围，不限制游戏进程。

### 部署与 ReShade

工具只检测所选鸣潮安装实际可加载的 ReShade，优先复用兼容版本；需要安装时使用随包材料，需要升级已有版本时会提示。其他游戏安装的 ReShade 不会被当作鸣潮的组件。

“多帧生成部署”开关决定部署内容，关闭它**不会卸载已安装的插件**。Fixed 与 Dynamic 共用组件，不需要安装两套包。部署和清除均应在游戏退出后进行。

### 清除插件

点击 **清除插件**，核对提示后按部署记录清理工具负责的文件。用户原有的 ReShade、滤镜和其他插件会保留；由本工具安装的 ReShade 按来源记录处理，已被其他工具修改的文件不会被直接当作原部署文件清理。

清除不会恢复官方 DLL，之后可能需要通过官方启动器校验和修复。**不要依赖普通启动自动补齐文件。**

### 配置与手动维护

配置、部署记录和日志保存在 `data/`。移动或备份软件时请保留完整目录，避免丢失文件来源与清理记录。

需要自行更换主 MFG addon 时，材料位置为 `payload/files/addon/renodx-mfgunlock.addon64`。完整退出游戏后更换材料，再重新部署。自行替换上游插件不保证保留本项目的中文菜单和控件整合，也不代表独立倍率控制器能兼容新的运行库。

## 软件更新

### 在线更新

在“部署与维护”中可选择是否启用 **启动时自动检查更新**，也可以点击 **检查更新**。自动检查只查询版本，不会未经选择直接安装；网络异常不影响正常启动游戏。

检测到正式新版时，窗口显示版本号与更新说明，并提供以下操作：

- **立即更新：** 下载、校验后由更新器安装；下载期间可以取消。
- **暂不更新：** 保持当前版本，稍后再处理。
- **跳过这个版本：** 关闭该版本的自动提醒，手动检查仍可重新查看并更新。
- **本次游玩后帮我更新：** 等待本次游戏结束后自动更新启动器。尚未开始游戏时，等待下一次由本工具启动的游戏结束；主动退出启动器会取消预约。

游戏运行期间不会安装更新。预约更新时会等待游戏退出，再恢复启动器到前台继续；下载取消或失败后可手动重试。

### 离线更新

GitHub 和网盘分发的本项目已有安装均可使用离线更新包，不要求旧文件与某个固定发布版本完全一致。

1. 正常退出游戏，并从托盘完全退出启动器。
2. 下载发布页中以 **update.zip** 结尾的更新包并解压。
3. 找到原启动器目录。使用桌面快捷方式时，可右键选择“打开文件所在的位置”。
4. 将解压后的**整个独立更新文件夹**放入原启动器目录，运行其中的 **更新.exe**。不要只复制更新器，也不要运行 `update-payload` 中的程序。
5. 核对更新窗口显示的安装目录，等待备份和更新完成。
6. **打开启动器设置，点击“开始部署”，完成后再启动游戏。**

```text
鸣潮 FPS Unlock/
├─ WuWaFpsUnlock.exe
├─ data/
├─ payload/
└─ 更新文件夹/
   ├─ 更新.exe           ← 运行此文件
   └─ update-payload/
```

更新期间请勿关闭更新窗口或启动器，也不要启动游戏。更新器会自动完成必要的退出与重新打开，并刷新或创建对应的桌面快捷方式。遇到占用提示时请完全退出相关程序；权限请求按 Windows 的正常机制处理。

**无论采用哪种更新方式，更新完成后都需要重新部署一次。** 更新包替换启动器及组件材料，重新部署后游戏才会使用相应插件。

更新成功后可以删除更新文件夹。需要保留回退能力时，请保留安装目录中的备份文件夹。

## 备份与回退

更新前，工具会备份本机实际使用的程序与组件，回退目标是这份备份，而非固定的上一发布版本。每次成功更新后保留最近一次有效备份，并清理能安全识别的旧备份；无法识别或存在额外文件的备份可能被保留。

回退步骤：

1. 正常退出游戏，打开启动器设置。
2. 在“部署与维护”中点击 **回退版本**，确认后等待恢复完成。
3. **重新部署一次，再启动游戏。**

没有可用备份或已经回退时，按钮不可点击。也可以在退出启动器后运行更新文件夹中的 **回退.cmd**，或备份文件夹中的 **rollback.cmd**。

回退恢复旧程序与组件材料，保留当前配置和部署记录，不直接修改游戏文件。请勿删除 `update-backup-日期-编号` 备份文件夹，除非已不再需要回退。

## 常见问题

**目标设为 160，实际帧率为什么更低？**

目标值不是性能保证。先确认修改后已重新启动游戏，再查看画质、场景负载及其他限帧设置。多帧生成目标、FPS 解锁目标和计数器显示值不是同一项数据。

**更新后为什么游戏内还是旧菜单？**

先完整退出游戏，在新版启动器设置中重新部署，再启动游戏。仅更新启动器不会替换已经加载的游戏插件。

**为什么有些倍率选项是灰色的？**

先检查当前使用 Fixed 还是 Dynamic；不适用的控件会禁用。运行时控制还需要对应组件和兼容性条件满足。

**为什么检测不到 Pre-release？**

自动检查和手动“检查更新”均只提供正式 Release。Pre-release 请在 GitHub 发布页下载。

**为什么托盘里已有启动器，双击快捷方式后没有新开窗口？**

工具采用单实例运行，双击快捷方式会恢复已有窗口，不再创建第二个实例。

**部署提示文件缺失，或清除后游戏无法启动怎么办？**

先通过官方启动器进行文件校验和修复，确认游戏正常启动，再重新部署。第三方插件也可能随游戏更新失去兼容性。

报告问题时，请说明工具版本、Windows 与驱动版本、启用的功能、操作步骤及相关日志；分享截图或日志前请遮挡 UID 和其他个人信息。
