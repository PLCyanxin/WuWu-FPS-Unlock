# 鸣潮 FPS Unlock v1.2.5Beta

本版升级了多帧生成组件，扩展运行库检测，加入游戏内 DLSS 模型预设选择，并采用重新整理的中文菜单。**这是 Beta 预发布版本，请在发布页手动下载；稳定版用户不会收到本版自动更新提示。**

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

> [!IMPORTANT]
> **仅适用于 NVIDIA GeForce RTX 40 系列显卡和鸣潮官方启动器版本。** 建议保留可用安装的备份，再测试本版。不同驱动和运行库组合的兼容性仍需验证；本版不保证解决所有高倍率拒绝或帧生成异常。

## 更新内容

- **升级多帧生成组件：** DLSS-G 插件基于上游 **MFG Unlock 1.7.2**，保留游戏默认、固定倍率（Fixed）、Dynamic 和关闭模式，以及已保存的倍率、Dynamic 最大倍率控制和菜单按键。
- **调整运行库检测：** 公开 Dynamic 接口按 **Streamline ≥ 2.14.1、DLSS-G ≥ 310.9.1** 检查版本资格，更高版本不再仅因版本号被排除；仍需实际运行库报告支持。切换运行库后重新确认能力，避免沿用旧状态。
- **提供游戏内模型预设选择：** 可在画质页选择 DLSS 超分辨率和光线重建模型预设。可用项及生效时机取决于游戏和运行库，NVIDIA App 的模型覆盖优先于游戏内选择。
- **更新游戏内菜单：** 重新整理倍率、画质、延迟和诊断信息，提供中文标签、状态与选项说明；保留 Dynamic、DLSS-G、Reflex 等技术名称，便于对照设置和反馈日志。
- **支持后续版本升级：** 同一数字版本按 **Beta → RC → 正式版** 比较。后续 v1.2.5RC 作为正式 Release 公开后，本版可通过启动器检查和获取更新，无需重新下载完整版。

## 使用方法

### 已有安装

1. 正常退出鸣潮，并从托盘完全退出启动器。
2. 下载 `WuWaFPSUnlock-1.2.5Beta-update.zip`，保留独立更新文件夹结构，将整个文件夹放入原启动器目录。
3. 运行其中的 **更新.exe**。**更新期间请勿关闭更新窗口与游戏启动器。**
4. 更新完成后，在启动器设置中点击 **开始部署**，核对计划并重新部署一次，再完整重启游戏。

更新会保留原设置并备份更新前的实际安装。成功后可以删除独立更新文件夹，请保留安装目录中的回退备份；需要恢复时，在设置中选择 **回退版本**。回退完成后同样需要重新部署。

### 首次安装

下载 `WuWaFPSUnlock-1.2.5Beta-win-x64.zip`，完整解压到鸣潮游戏目录之外，运行 `WuWaFpsUnlock.exe`。在设置中选择游戏和所需组件后再部署。只使用帧率解锁无需部署多帧生成；只使用多帧生成也不必开启帧率解锁。

## 兼容性与反馈

- **Dynamic 最大倍率仍为实验性功能。** 您选择的是上限，实际倍率由 NVIDIA Dynamic 根据负载和运行库能力决定，不保证达到所选倍率。
- 运行库满足最低版本不代表所有扩展控制均可用。倍率热切换、关闭和倍率观测涉及的私有接口会另行检查；本版包含 Streamline 2.14.1 及特定 2.14.16 的适配，其余未知接口不会强行修改。新适配仍需更多游戏内反馈。
- 更换插件后必须完整退出并重启游戏，不支持依靠插件热重载完成升级。出现问题时，请在设置中导出日志，附上显卡、驱动、模式与复现步骤后[提交 Issue](https://github.com/PLCyanxin/WuWu-FPS-Unlock/issues/new/choose)。
- 自动和手动检查均只提供 GitHub **正式 Release**，不会提供标为 Pre-release 的版本；当前 Beta 需要手动下载。已安装同号 RC 的用户不会因同一 RC 再次发布收到重复提示。
