这一版主要更新多帧生成插件，并加入更方便的更新与回退方式。

- **看得见的 Dynamic 倍率**：在游戏内 MFG Unlock 面板查看当前实际生成倍率。
- **更多画面调优选择**：新增部分实验性选项，按需尝试；若出现异常，可关闭相应选项。
- **保留自己的旧版本**：更新前备份本机程序与组件，回退时恢复你实际使用过的文件，包括自行更换的 addon。

## 选择下载

- 第一次使用：`WuWaFPSUnlock-1.1.1-win-x64.zip`，完整解压后运行 `WuWaFpsUnlock.exe`。
- 已有本项目旧版：`WuWaFPSUnlock-1.1.1-update.zip`，无需重新下载整套材料，GitHub 和网盘旧版均可使用。

## 更新步骤

1. 退出游戏和托盘中的启动器。
2. 把解压后的整个更新文件夹放进原启动器目录，运行其中的 `更新.exe`。桌面快捷方式可通过右键“打开文件所在的位置”找到原目录。
3. 更新器自动匹配所在目录及最多三层上级目录中的启动器，并先备份再更新。出现多个候选时会停止并提示。
4. 更新完成后会刷新桌面快捷方式，没有对应快捷方式时自动创建。
5. **更新成功后，打开启动器，在设置中重新部署一次，再启动游戏。**

更新完成后可以删除更新文件夹。备份独立保存在安装目录的 `update-backup-日期-编号` 文件夹中，保留它即可保留回退能力。

## 不满意可以回退

退出游戏和启动器，双击更新文件夹中生成的 `回退.cmd`。如果更新文件夹已经删除，运行本次备份目录里的 `rollback.cmd`。

恢复的是更新前本机实际使用的程序与组件，不是某个固定旧 Release。配置和部署记录也会备份，但自动回退保留当前记录，避免丢失重新部署后的文件归属信息。

**回退完成后同样需要打开启动器，重新部署一次。** 更新器与回退器都不会自动写入游戏目录。

实验性选项的效果因设备和场景而异。目标 FPS、Dynamic 设置值与实际输出不同，实际效果请在游戏内确认。
