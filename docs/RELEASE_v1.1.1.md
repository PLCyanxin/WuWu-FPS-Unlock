# 鸣潮 FPS Unlock v1.1.1

启动器现在可以检查新版，并直接配合更新包完成更新。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

## 新增功能

- **更新由你决定**：设置中可以关闭或开启启动时自动检测，也可以随时手动检查。
- **先看更新内容**：发现新版时展示更新说明，选择立即更新或暂不更新。
- **跳过这个版本**：不想更新某一版可以勾选跳过，更高版本仍会提醒；手动检查可重新查看。
- **更新过程衔接**：下载并校验后，启动器退出，独立更新器自动备份、安装并维护桌面快捷方式。

RC 版本参与正常更新检测；同数字正式版高于 RC。原有的多帧生成、Dynamic 实际倍率显示、实验性画面选项及回退功能继续保留。

## 第一次升级

已有 v1.1.1RC 或更早版本，请下载 `WuWaFPSUnlock-1.1.1-update.zip`。退出游戏和启动器，将整个更新文件夹放进原启动器目录，双击 `更新.exe`。请保留独立更新文件夹，不要把新协议包平铺进旧程序目录。

首次使用请选择 `WuWaFPSUnlock-1.1.1-win-x64.zip`，完整解压后运行 `WuWaFpsUnlock.exe`。

**更新成功后，打开启动器，在设置中重新部署一次。** 更新完成后可以删除更新文件夹；保留安装目录中的 `update-backup-日期-编号` 即可保留回退能力。

如需回退，退出游戏及启动器，运行更新文件夹内的 `回退.cmd`，或备份目录中的 `rollback.cmd`。恢复的是更新前自己的程序和组件，当前配置与部署记录保留。**回退后同样需要重新部署一次。**

游戏运行时不能安装更新；网络或校验失败不会自动覆盖现有程序。
