# 鸣潮 FPS Unlock v1.2RC

为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署。

## 新增：实验性 Dynamic 最大倍率

可以为 NVIDIA 原生 Dynamic 多帧生成设置最大倍率，默认 **4x**。实际倍率仍由原生 Dynamic 根据场景和负载选择，上限不是固定倍率，也不保证实际输出帧率。

可选值为 **0、2、3、4、5、6**。0 表示不覆盖 NVIDIA 默认行为，不代表驱动没有自己的上限；5x、6x 是否可用取决于设备及运行时。该选项仅作用于 Dynamic，不改变 Fixed 的倍率设置。

**本版不支持运行中热切换上限。** 游戏内修改会保存为下次启动使用的配置，必须完全退出并重新启动游戏才能应用。

## 如何设置

1. 首次部署前，在启动器设置的“多帧生成部署”中选择 Dynamic 最大倍率，默认保持 4x 即可。确认文件映射后完成部署，再启动游戏。
2. 后续调整可在游戏内 ReShade 的 **MFG Unlock** 面板修改 **Dynamic maximum multiplier**。
3. 完全退出游戏，再重新启动。仅关闭面板、返回标题界面或关闭再开启 Dynamic，不能代替重新启动游戏。
4. 若再次从启动器部署，将以启动器中保存的选值写入配置；部署前请核对该值，避免覆盖游戏内另行保存的选择。

驱动预检查条件 **595.41** 仅用于 Dynamic，不是整个启动器或帧率解锁功能的统一门槛。驱动条件满足、文件部署完成、读取到上限配置和游戏内实际生效是不同状态。可在 MFG Unlock 诊断中检查配置与读取状态，并结合实际倍率观察；没有足够场景负载时，不能仅凭倍率暂未超过 4x 判断硬上限已验证。

更新标签及下载包使用三段版本号 `1.2.0RC`，与界面显示的 v1.2RC 为同一版本。

## 更新已有安装

支持在线更新的版本可在启动器中检查更新，也可使用本版离线更新包。更新前请正常退出游戏。

**更新完成后，请打开启动器，在设置中重新部署一次。** 更新包更新的是启动器目录中的程序与组件材料，不会自动把新版 addon 部署到游戏目录。重新部署后再启动游戏；部署前可确认希望使用的初始上限。

首次使用请选择完整版。离线更新时保留完整的独立更新文件夹，放进原启动器目录后运行其中的 `更新.exe`。更新前备份及回退入口请妥善保留；回退后也需要重新部署一次。

更新完成后可以删除更新文件夹；请保留安装目录中的 update-backup 备份以便回退。回退恢复更新前的实际文件，回退后同样需要重新部署。
