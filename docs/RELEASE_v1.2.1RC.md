# 鸣潮 FPS Unlock v1.2.1RC

为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署。

## 更新摘要

Dynamic 最大倍率支持游戏内实时调整，默认4x；支持游玩结束后自动更新启动器，以及一键回退到更新前版本。优化启动器界面布局。**安装或回退后，请在启动器设置中重新部署一次。**

## Dynamic 最大倍率

在 ReShade 的 **MFG Unlock → Experimental live Dynamic maximum** 中选择2x–6x，无需退出游戏即可调整。每次启动游戏默认上限为4x；游戏内修改只作用于本次运行，重新启动游戏后恢复4x。Native bound (restore) 恢复原生上限。

该功能仍为实验性功能。选择的是上限，实际倍率由 NVIDIA 原生 Dynamic 根据负载、硬件、驱动和运行库能力决定，不保证达到所选倍率。兼容性检查未通过时不会启用热控制；参数提交记录不等于实际生成倍率。

首次升级后，请完整退出游戏、重新部署并重新启动一次。之后调整最大倍率无需重启或再次部署。启动器中不再需要设置部署倍率。

## 更方便地更新

发现正式新版时，可选择“立即更新”或“本次游玩后帮我更新”。预约后，游戏期间不会更新；本次游戏结束时，启动器会恢复到前台并开始更新。尚未开始游戏时，预约等待下一次由此启动器启动的游戏结束；主动退出启动器会取消本次预约。

“跳过这个版本”仅关闭该版本的自动提醒，手动“检查更新”仍可更新。更新检查只提供正式 Release，Pre-release 请在发布页手动下载。

更新期间请勿关闭窗口与游戏启动器，程序会自动完成必要的退出和重新打开。在线、预约及手动离线更新成功后，都会提示重新部署。

## 使用方法

- 首次使用：下载 **win-x64.zip** 完整版，解压后运行 WuWaFpsUnlock.exe。
- 已有安装：下载 **update.zip**，将整个独立更新文件夹解压到原启动器目录内，再运行其中的 更新.exe。不要只复制更新器，也不要直接运行 update-payload 内的程序。
- **更新完成后，请打开启动器设置，点击“开始部署”重新部署一次，再启动游戏。**
- 不满意此次更新时，退出游戏，在设置中点击“回退版本”。它恢复本机更新前的实际程序与组件材料，并保留当前配置和部署记录。**回退后也需要重新部署。**

成功更新只保留最近一次更新前的有效备份。没有可用备份或已经回退时，回退按钮不可点击。更新完成后可删除更新文件夹；请保留安装目录中的最近一次备份，以便回退。

本版同时优化了设置页间距。更新说明较长时可滚动阅读，更新与取消按钮保持可见。
