# 鸣潮 FPS Unlock v1.2.1RC

更新摘要

Dynamic 最大倍率改为游戏内运行时调整，默认4x，移除启动器部署选项与旧静态上限；新增版本回退入口，优化设置布局和更新弹窗。更新后请退出游戏，在设置中重新部署一次，再完整启动游戏。

## Dynamic 运行时控制

在 ReShade 的 MFG Unlock 面板中使用 Experimental live Dynamic maximum，可在游戏运行时调整2x–6x上限。默认4x，临时选择只用于本次运行。实际倍率由 NVIDIA 原生 Dynamic 调度，受场景负载、硬件与驱动能力限制；选择6x不代表必定生成6x。

不再应用旧的启动静态4x上限。首次升级需重新部署并完整退出旧游戏进程，后续热调整无需重启。

热控制仍为实验功能，仅适配随包运行库；兼容性检查失败时停用并显示原因。参数提交记录不能代替实际倍率观察。

## 更新与回退

新增“本次游玩后帮我更新”：游戏期间等待，退出后保留启动器并在前台执行更新。任意方式更新成功后均提醒重新部署。跳过版本仅关闭自动提醒，手动检查仍可更新。

设置中的“回退版本”恢复最近一次更新前的本机程序与组件材料，保留当前配置和部署记录。没有可用备份或已经回退时按钮不可用。成功更新后清理旧备份，只保留最近一次；无法安全识别的备份保留并提示。

更新和回退后均需重新部署。更新文件夹可删除，请保留安装目录中的最近一次备份以便回退。

更新提示限制最大高度，长说明可滚动，底部操作按钮始终可见。设置页调整了卡片、文字和窗口边距。
