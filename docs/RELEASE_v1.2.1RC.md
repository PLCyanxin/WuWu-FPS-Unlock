# 鸣潮 FPS Unlock v1.2.1RC

为《鸣潮》提供帧率解锁、游戏启动和可选的多帧生成部署。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

## 更新摘要

本版支持在游戏内实时调整 Dynamic 最大倍率，并自动保存所选上限。启动器支持在本次游玩结束后自动更新，也支持恢复到更新前的版本。此外，本版优化了启动器界面布局。**更新或回退完成后，请在启动器设置中重新部署一次。**

## Dynamic 最大倍率

当场景负载较高、基础渲染帧率较低时，Dynamic 可能提高生成倍率，以接近您设置的目标帧率。更高的生成倍率可能增加处理开销和延迟，让画面与操作之间产生黏滞感，影响游戏体验。您可以通过降低 Dynamic 最大倍率，限制过高的生成倍率，在输出帧率与操作响应之间取得平衡。降低上限后，实际输出帧率也可能下降。

相比 v1.2RC，本版支持在游戏内实时调整 Dynamic 倍率上限。您可以根据当前场景和操作感受随时调整，无需退出游戏；插件会自动保存您的选择，供后续启动继续使用。

您可以在 ReShade 的 **MFG Unlock → Experimental live Dynamic maximum** 中选择2x–6x，无需退出游戏即可调整。插件在首次使用时将上限设为4x，此后会自动保存您的选择，并在后续启动时继续使用。例如，您将上限改为6x后，只要不再次修改，后续启动仍会使用6x。选择 **Native bound (restore)** 可以恢复原生上限。

该功能仍为实验性功能。您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。NVIDIA 原生 Dynamic 会根据负载、硬件、驱动和运行库能力决定实际倍率，因此实际倍率不一定达到您设置的上限。插件只有在兼容性检查通过后才会启用运行时调整功能；参数提交记录不能证明游戏实际达到了相应倍率。

升级到本版后，请先完整退出游戏，再在启动器中重新部署组件，然后重新启动游戏。完成这次部署后，您可以直接在游戏内调整最大倍率，无需再次部署或重启游戏。

## 更方便地更新

启动器发现正式新版时，会显示更新说明，并提供“立即更新”和“本次游玩后帮我更新”选项。如果您选择后者，启动器会等待本次游戏结束，再恢复到前台并开始更新。如果您尚未开始游戏，启动器会等待下一次由它启动的游戏结束后再更新。主动退出启动器会取消本次预约。

“跳过这个版本”只关闭该版本的自动提醒。您仍可在设置中点击“检查更新”，重新进入更新流程。启动器只检查正式 Release。Pre-release 请在发布页手动下载。维护者验证版本稳定后，会将该版本从 Pre-release 转为 Release，供启动器检查和更新。

更新期间，请勿关闭更新窗口或游戏启动器。更新器会自动完成必要的退出和重新打开操作。无论您选择立即更新、游玩后更新还是手动离线更新，启动器都会在更新成功后提示“更新完成，请点击重新部署”。

## 使用方法

- 如果您首次使用本工具，请下载 **win-x64.zip** 完整包，解压后运行 **WuWaFpsUnlock.exe**。
- 如果您已经安装本工具，请下载 **update.zip**，将解压后的整个独立更新文件夹放入原启动器目录，再运行其中的 **更新.exe**。请勿只复制更新器，也不要直接运行 update-payload 内的程序。
- **更新完成后，请打开启动器设置，点击“开始部署”，等待部署完成后再启动游戏。**
- 如果您希望恢复更新前的版本，请先退出游戏，再在启动器设置中点击“回退版本”。更新器会恢复本机更新前的程序和组件材料，并保留当前配置及部署记录。**回退完成后，请重新部署一次。**

更新器会在每次成功更新后保留最近一次更新前的有效备份，并清理可以安全识别的旧备份。如果没有可用备份，或已经完成回退，“回退版本”按钮将不可点击。更新完成后，您可以删除更新文件夹；如果您希望保留回退能力，请保留安装目录中的备份文件夹。

本版优化了设置页的间距。更新说明较长时，您可以滚动阅读；更新和取消按钮会始终显示在窗口中。
