# 鸣潮 FPS Unlock v1.2.3

> [!IMPORTANT]
> **重要更新，推荐所有用户更新。** 仅适用于 NVIDIA GeForce RTX 40 系显卡和鸣潮官方启动器版本，未来不扩大支持范围。

本次更新适配新版官方启动器的包体管理，升级多帧生成组件并完成新增菜单汉化，新增统一的帧生成模式选择，同时修复游戏路径关联、部署材料定位与 Intel E 核识别问题。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

## 更新内容

- **升级多帧生成组件：** 基于上游 MFG Unlock 1.3.0，完成新增菜单汉化，提供画质、稳定性、Reflex 与帧节奏控制选项。保留倍率热切换、设置保存及关闭帧生成的功能。部分实验性选项需要重启游戏，以菜单提示为准。
- **新增帧生成模式选择：** 在游戏内选择 Dynamic、固定倍率（Fixed）或游戏默认，选择即启用，仅显示对应的派生设置。游戏默认取消自定义倍率覆盖，由游戏设置控制；它不等于关闭帧生成。模式与倍率会自动保存。
- **适配官方包体档位管理：** 主页提供极致、高清、流畅三档选择，移除“跟随官方”；升级时保留已有明确选择，原自动配置优先读取新版官方启动器保存的档位。切换档位在下一次启动游戏时生效，无需重新部署插件。
- **新增包体下载状态：** 绿色表示已下载，红色表示未下载，黄色表示检测到该档位的下载资源正在写入；无法读取记录时显示“未捕获”。启动时检测状态，展开菜单后持续更新。暂停下载后，黄色会在短暂等待后消退。

## Bug 修复

- **修复游戏路径关联问题：** 选择官方启动器目录、游戏根目录或正确的游戏 EXE 后，同步定位对应安装，避免目录与 EXE 不一致导致无法部署。
- **修复部署材料定位问题：** 移动或更新启动器后，优先使用当前安装随附的材料，避免继续引用旧安装。缺少清单或组件时明确提示恢复方法，不再要求到游戏目录选择 manifest.json。
- **修复 Intel E 核识别问题：** 不再把临时停放的 E 核误判为不可用。后台空闲时使用已识别的 E 核，回到前台、执行关键操作或创建子进程前恢复原调度范围，避免把限制传递给游戏。

## 使用方法

### 首次安装

下载 **WuWaFPSUnlock-1.2.3-win-x64.zip**，完整解压到固定目录，再运行 **WuWaFpsUnlock.exe**。保留 EXE 同目录下的 `payload`、`components`、`licenses` 等随包目录，不要单独移动主程序。

先通过官方启动器完成游戏更新及所需包体的下载。在本工具设置中选择鸣潮，主页选择对应档位。包体资源的下载与安装仍由官方启动器完成，本工具不会代为下载、转换或补齐资源。

帧率解锁和多帧生成可以分别使用。仅使用帧率解锁时，设置目标 FPS 后直接开始游戏，无需部署插件；使用多帧生成时，先完整退出游戏，在设置中开启“多帧生成部署”，点击 **开始部署**，核对计划并确认，之后通过本工具以 DX12 启动。

### 更新已有安装

1. 正常退出游戏，并从托盘退出启动器。
2. 下载 **WuWaFPSUnlock-1.2.3-update.zip**，把解压后的整个更新文件夹放入原启动器目录，保持其内部结构完整。
3. 运行更新文件夹中的 **更新.exe**。不要单独复制更新器，也不要运行 `update-payload` 内的程序。
4. **更新期间请勿关闭更新窗口与游戏启动器。**
5. 更新成功后，按提示打开启动器设置，点击 **开始部署**，重新部署一次后再开始游戏。

更新包需要已有完整安装，不能代替首次安装包。更新成功后可以删除更新文件夹；请保留安装目录中的最新备份。如需回退，在设置中点击 **回退版本**，恢复更新前本机实际使用的程序与组件。**回退后同样需要重新部署。**

### 游戏内设置

按 **Home** 打开 ReShade，进入 **MFG Unlock**，选择“帧生成模式”并调整对应倍率。首次使用的自定义倍率为 4x，之后继续使用已保存的选择；在倍率菜单中选择“关闭”可停用对应模式的帧生成。

**Dynamic 最大倍率仍为实验性功能。** 所选数值是允许使用的上限，实际倍率由 NVIDIA 根据负载、硬件、驱动与运行库能力决定。兼容性检查未通过时不会启用运行时控制。使用自定义目标输出帧率前，请检查 VSync 与 G-SYNC 等显示同步设置。

本版为正式 **Release**，启动器可检测并提供更新。GitHub 下载较慢或中断时，可尝试使用网络加速器。
