# v1.2.3

本次更新适配新版官方启动器的包体管理，完善包体档位选择和部署路径识别，并升级多帧生成组件。

- 主页提供极致、高清、流畅三档选择，选择后保存，下次启动游戏生效。
- 包体菜单显示下载状态：绿色为已下载，红色为未下载，黄色为检测到该档位正在写入下载资源。下载暂停后，黄色状态会在短暂等待后消退；记录无法读取时显示“未捕获”。
- 移除“跟随官方”选项。升级时保留已有明确档位；原自动配置优先读取新版官方启动器保存的档位。
- 完善游戏目录与可执行文件的关联识别。选择官方启动器目录、游戏目录或游戏可执行文件时，同步定位游戏安装路径。
- 完善便携安装的材料清单定位，减少移动或更新启动器后重新选择部署清单的情况。

- 多帧生成组件升级至上游 1.3.0，新增画质、稳定性、Reflex 与帧节奏控制选项，并完成新增菜单的汉化。保留游戏内倍率热切换、设置保存及固定帧生成与 Dynamic 的独立关闭选项。部分实验性画质与帧节奏设置仍需重启游戏后生效，请以对应菜单提示为准。

## 使用方法

先在官方启动器中下载所需包体，再在本工具主页选择对应档位。更改包体档位无需重新部署插件；包体下载与安装由官方启动器完成。旧安装没有分档记录时，下载状态显示“未捕获”，仍可手动选择对应档位。

从旧版升级后，请完整退出游戏，完成更新，再在设置中重新部署一次。
