# 鸣潮 FPS Unlock v1.2.2

本次更新升级了多帧生成组件，由本项目完成菜单汉化，新增帧生成关闭选项和大版本预下载提醒，并优化 Home 菜单鼠标表现和启动器运行效率。打开工具时会后台检查预下载状态，发现尚未完成的预下载后打开对应官方启动器并提示；已下载完成时不重复提醒，检查失败不影响正常启动游戏。

> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

## 更新内容

### 多帧生成

- 将多帧生成插件升级至上游 **1.1.5**，并由本项目完成菜单汉化。
- **固定帧生成倍率**和 **Dynamic 最大倍率**新增“关闭”选项，两项设置独立保存。这将便于您在凹分时关闭帧生成，避免帧生成带来的额外延迟。
- 开启 Dynamic 后，固定帧生成倍率选项不可调节；关闭 Dynamic 后，Dynamic 最大倍率选项不可调节，方便区分当前使用的模式。
- 完善倍率状态显示，使用“关闭”“1x–6x”或“未捕获”表示当前状态。

### Home 菜单

- 优化鼠标表现，使用系统光标，使指针刷新可跟随桌面刷新率，减少低帧率下的迟滞感。菜单内容仍随游戏帧率刷新。
- 汉化多帧生成选项，方便识别和调整。
- 拖动标题栏可移动菜单；按住 **Shift** 拖动可调整停靠位置，减少误触。

### 性能优化

- 重构帧率解锁模块，减少不必要的内存写入，优化扫描与通信管理。
- 优化环境检测和部署过程，合并重复目录扫描，减少磁盘访问。
- 减少插件菜单的重复计算与后台空闲唤醒。
- 在支持且能够识别的 Intel 混合架构处理器上，启动器后台空闲任务优先使用 E 核；前台及关键操作恢复原处理器范围，游戏进程不受限制。

以上优化主要减少工具自身的处理开销，不代表游戏 FPS 会按固定比例提升。实际效果取决于硬件配置、画质和场景。

### 启动器



- 修正 Windows 11 系统名称显示，完善 HAGS 状态检测。
- 优化界面布局与提示文字。
- 改进历史更新备份的识别与清理。成功更新后保留最近一次有效备份，无法安全识别的文件不会被强制删除。

## 使用方法

### 首次安装

下载 **WuWaFPSUnlock-1.2.2-win-x64.zip**，解压到固定目录，运行 **WuWaFpsUnlock.exe**。

仅使用帧率解锁时，无需部署多帧生成组件。需要多帧生成时，请在设置中选择游戏路径并完成部署。

### 更新已有安装

1. 正常退出游戏，并从托盘退出启动器。
2. 下载 **WuWaFPSUnlock-1.2.2-update.zip**。
3. 将解压后的**整个更新文件夹**放入原启动器目录，运行其中的 **更新.exe**。请勿单独复制更新器，也不要运行 `update-payload` 中的程序。
4. 更新期间请勿关闭更新窗口或启动器，等待更新完成提示。
5. **打开启动器设置，点击“开始部署”，完成后再启动游戏。**

更新器会备份本机更新前的程序和组件，并保留配置与部署记录。更新完成后可以删除更新文件夹；如需保留回退能力，请保留安装目录中的备份文件夹。

### 回退版本

正常退出游戏后，在启动器设置中点击 **回退版本**，即可恢复本机更新前的程序和组件。当前配置与部署记录会保留。

**回退完成后，同样需要在设置中重新部署一次。**

## 下载与更新说明

本版为正式 **Release**，可在启动器设置中点击“检查更新”，或从发布页手动下载完整包与更新包。更新完成后，请在设置中重新部署一次。
