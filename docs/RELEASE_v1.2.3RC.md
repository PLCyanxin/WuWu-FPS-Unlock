# 鸣潮 FPS Unlock v1.2.3RC

> [!IMPORTANT]
> **重要更新，推荐所有用户更新。** 本版适配游戏包体档位启动参数，解决缺少该参数时出现“kuro: Use launcher to start game!”、无法启动游戏的问题。

本次更新新增包体档位选择，并完善大版本预下载完成后的后续更新提醒。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

## 更新内容

- **适配包体档位启动参数：** 默认读取官方启动器的包体档位设置，并在启动游戏时传入对应参数；保留多帧生成所需的 DX12 启动方式。
- **新增包体档位选择：** 在主页“开始游戏”旁点击“包体档位”，可选择跟随官方、极致（uhd）、高清（hd）或流畅（sd）。选择会自动保存，在下一次启动游戏时生效。
- **完善开服后的更新提醒：** 已预下载的版本正式开放后，若本机尚未完成版本安装，会打开官方启动器并提示完成后续补充下载与安装。预下载阶段勾选“不再提醒”不会屏蔽这一阶段的提醒；完成安装后不再提示。

## 使用方法

### 安装或更新

首次使用请下载 **WuWaFPSUnlock-1.2.3RC-win-x64.zip**，解压后运行 **WuWaFpsUnlock.exe**。

已有安装请按以下步骤更新：

1. 正常退出游戏，并从托盘退出启动器。
2. 下载 **WuWaFPSUnlock-1.2.3RC-update.zip**，将解压后的整个更新文件夹放入原启动器目录。
3. 运行更新文件夹中的 **更新.exe**。请勿单独复制更新器，或运行 `update-payload` 内的程序。
4. 更新期间请勿关闭更新窗口与游戏启动器。
5. 更新完成后，打开启动器设置，点击 **开始部署**，完成后再启动游戏。

更新完成后可以删除更新文件夹。更新前会备份本机实际使用的程序与组件；如需回退，在设置中点击 **回退版本**，回退后同样需要重新部署。请保留安装目录中的备份文件夹。

### 包体档位

建议保留“跟随官方”。需要手动指定时，请选择与官方启动器已安装资源相对应的档位。**此选项只设置游戏启动参数，不会下载、转换或补齐包体；资源下载与安装必须在官方启动器完成。** 高清（hd）启动已通过实机验证，极致（uhd）与流畅（sd）尚未完成实机验证。

### 下载与更新

本版为正式 **Release**，可在启动器设置中点击“检查更新”，或从本发布页手动下载完整包与更新包。更新完成后，请在设置中重新部署一次。
