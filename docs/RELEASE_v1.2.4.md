# 鸣潮 FPS Unlock v1.2.4

本次更新改善帧率解锁模块的持续维持与自动恢复能力，新增启动器及 ReShade 日志合并导出，并提供可自定义的菜单按键和统一的帧生成关闭选项，同时提升部署、清除、更新与回退的可靠性。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

> [!IMPORTANT]
> **仅适用于 NVIDIA GeForce RTX 40 系列显卡和鸣潮官方启动器版本，未来不扩大支持范围。** 已有安装可通过启动器的“检查更新”获取本版，也可使用本页的离线更新包。

## 更新内容

- **修复帧率解锁维持失效：** 改善暂时读取或写入失败后不再继续维持的问题。模块会保留控制会话，在原帧率设置恢复可用并通过校验后自动继续维持目标值；写入后回读确认结果，避免仅凭指令发送成功显示已生效。
- **新增合并导出日志：** 在设置的“运行日志”中点击“导出日志”，可保存启动器运行记录、配置与组件信息、帧率解锁模块状态，以及所选游戏的 ReShade 日志。没有 ReShade 日志时明确标记，方便反馈问题。
- **自定义菜单按键：** 默认使用 Home，可录入单键或组合键；点击右侧 **×** 可清空绑定并显示“未设置”。需要恢复时，在按键框中重新录入 Home。修改在重新部署或下一次通过本工具启动游戏时应用。
- **统一关闭帧生成：** 在“帧生成模式”中选择“关闭”，即可关闭固定帧生成（Fixed）或 Dynamic；再次切回其他模式时保留已保存的倍率。这将便于您在凹分时关闭帧生成，避免帧生成带来的额外延迟。
- **改善部署与一键清除：** 官方更新改变运行库位置后，可核对并重建部署路径记录；已有完整记录时，即使原材料缺失，也可清除已登记且未被修改的组件。保留用户原有的 ReShade、滤镜及其他插件。
- **增强配置兼容性：** 正确保留含逗号的路径与其他插件条目，重新部署保留游戏内已保存的模式和倍率；发现配置歧义时停止自动修改并提示。
- **改善更新、回退及启动反馈：** 更新意外中断后可重新运行更新包，或使用备份中的“恢复.cmd”处理未完成的操作。启动失败时保留启动器及错误提示；回退前检查游戏状态，并保留本机最近一次更新前的有效备份。
- **优化环境信息显示：** 显卡与驱动版本分别显示，统一环境信息和日志操作的字体与文字样式。

## 使用方法

### 首次安装

下载 **WuWaFPSUnlock-1.2.4-win-x64.zip**，完整解压到固定目录，运行 **WuWaFpsUnlock.exe**。请保留随包的 `payload`、`components`、`licenses` 等目录，并将本工具放在鸣潮游戏目录之外。

先通过官方启动器完成游戏更新及所需包体下载。在本工具设置中选择鸣潮，在主页选择已安装的包体档位。仅使用帧率解锁时，无需部署多帧生成组件；如需多帧生成，请先退出游戏，点击设置中的 **开始部署**，核对计划并确认，再通过本工具以 DX12 启动游戏。

### 更新已有安装

可在设置中点击 **检查更新**，选择立即更新或 **本次游玩后帮我更新**。也可使用离线更新包：

1. 正常退出游戏，并从托盘完全退出启动器。
2. 下载 **WuWaFPSUnlock-1.2.4-update.zip**，将解压后的整个独立更新文件夹放入原启动器目录，保持内部结构完整。
3. 运行其中的 **更新.exe**。不要单独移动更新器，也不要运行 `update-payload` 内的程序。
4. **更新期间请勿关闭更新窗口与游戏启动器，也不要启动游戏。**
5. 更新完成后，启动器会打开设置并提示 **“更新完成，请点击重新部署”**。请点击 **开始部署**，完成后再启动游戏。

更新包用于已有完整安装，不能代替首次安装包。更新成功后可以删除更新文件夹；请保留安装目录中的最新备份，以便回退。

### 回退与游戏内设置

需要回退时，退出游戏，在设置中点击 **回退版本**，或运行备份目录中的 `rollback.cmd`。回退恢复本机更新前实际使用的程序与组件，保留当前配置和部署记录。**回退后同样需要重新部署。**

按 **Home** 或自定义菜单按键打开 ReShade，在 **MFG Unlock** 中选择 Dynamic、固定倍率（Fixed）、游戏默认或关闭，再调整对应选项。模式与倍率自动保存，关闭帧生成不会清空已保存的倍率。

**Dynamic 最大倍率仍为实验性功能。** 所选倍率是允许使用的上限，实际倍率由 NVIDIA 根据负载、硬件、驱动和运行库能力决定，不保证达到所选值。

完整功能及使用说明见 [项目主页](https://github.com/PLCyanxin/WuWu-FPS-Unlock)。
