# Dynamic 最大倍率

您可以在游戏内打开 ReShade 的 **MFG Unlock** 面板，先将 **帧生成模式** 设为 **Dynamic**，再通过 **Dynamic 最大倍率** 调整上限。插件在首次使用时将上限设为 **4x**，此后会自动保存您的选择，并在后续启动时继续使用。

## 什么时候需要调整

当场景负载较高、基础渲染帧率较低时，Dynamic 可能提高生成倍率，以接近您设置的目标帧率。更高的生成倍率可能增加处理开销和延迟，让画面与操作之间产生黏滞感，影响游戏体验。您可以通过降低 Dynamic 最大倍率，限制过高的生成倍率，在输出帧率与操作响应之间取得平衡。降低上限后，实际输出帧率也可能下降。

您可以根据当前场景和操作感受，在游戏内实时调整 Dynamic 倍率上限，无需退出游戏；插件会自动保存您的选择，供后续启动继续使用。

## 使用方法

1. 升级后，请完整退出游戏，在新版启动器中重新部署多帧生成组件，然后重新启动游戏。
2. 请打开游戏内的 MFG Unlock 面板，将帧生成模式设为 Dynamic，再选择所需的最大倍率。您可以选择最高 2x–6x，或选择 **跟随原生上限** 取消自定义上限。
3. 插件会在运行时应用新的上限，无需再次部署或重启游戏。您选择6x后，只要不再次修改，后续启动仍会使用6x。

您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。NVIDIA 原生 Dynamic 会根据目标帧率、负载、硬件、驱动和运行库能力决定实际倍率，因此实际倍率不一定达到您设置的上限。此功能不能突破运行库和硬件本身的能力限制。

最大倍率在游戏内设置，无需在启动器中指定部署倍率。插件通过 ReShade 保存游戏内选择；请确保 ReShade 配置文件可写，否则下次启动可能无法保留更改。

## 独立组件与升级

倍率控制由独立的 `wuwa-dynamicmax.addon64` 提供，`renodx-mfgunlock.addon64` 基于上游 1.3.0，集成中文菜单和界面桥接。开启多帧生成部署时，启动器会安装这两个组件。以后替换上游 MFG 插件时，无需重新合并倍率控制源码；完整退出游戏并重新部署后即可使用新插件。

游戏内的 **帧生成模式** 提供 **Dynamic**、**固定倍率（Fixed）**、**游戏默认** 和 **关闭**。选择模式后，下方只显示该模式对应的设置。Dynamic 与 Fixed 的倍率选择分别保存；切换模式不会覆盖另一模式已保存的倍率。选择游戏默认后，帧生成由游戏设置决定；游戏默认不等于关闭帧生成。

首次使用独立组件时，控制器会读取并迁移已有的倍率选择。配置保存在 ReShade 的 `[WuWa.DynamicMax]` 节中；后续部署不会重置它。请勿在游戏运行中删除或替换插件文件。

## 兼容性

运行时调整仍为实验性功能，仅支持随包适配的 Streamline 运行库。插件会检查运行库版本、线程和权限；检查失败时不会启用运行时调整。此功能使用针对指定版本的进程内适配，并非 NVIDIA 公开的上限设置接口。

第三方插件可能造成兼容性问题、崩溃或账号风险。请勿关闭安全软件或绕过系统权限来强行启用功能。

## 关闭帧生成

在 **帧生成模式** 中选择 **关闭**，即可停用帧生成，下面的倍率设置会隐藏。再次选择 Fixed 或 Dynamic 后，继续使用该模式上次保存的倍率；关闭不会清空倍率选择。关闭功能需要对应运行库控制能力可用；未通过兼容性检查时，这一选项将不可选择。已有的关闭状态在升级时会保留。

**跟随原生上限** 表示取消自定义 Dynamic 上限，不等于关闭帧生成。所有运行时控制均需通过组件兼容性检查。
