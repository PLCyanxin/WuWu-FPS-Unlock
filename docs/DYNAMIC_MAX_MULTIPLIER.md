# Dynamic 最大倍率

您可以在游戏内打开 ReShade 的 **MFG Unlock** 面板，通过 **Dynamic 最大倍率** 调整 Dynamic 最大倍率。插件在首次使用时将上限设为 **4x**，此后会自动保存您的选择，并在后续启动时继续使用。

## 什么时候需要调整

当场景负载较高、基础渲染帧率较低时，Dynamic 可能提高生成倍率，以接近您设置的目标帧率。更高的生成倍率可能增加处理开销和延迟，让画面与操作之间产生黏滞感，影响游戏体验。您可以通过降低 Dynamic 最大倍率，限制过高的生成倍率，在输出帧率与操作响应之间取得平衡。降低上限后，实际输出帧率也可能下降。

相比 v1.2RC，本版支持在游戏内实时调整 Dynamic 倍率上限。您可以根据当前场景和操作感受随时调整，无需退出游戏；插件会自动保存您的选择，供后续启动继续使用。

## 使用方法

1. 升级后，请完整退出游戏，在新版启动器中重新部署多帧生成组件，然后重新启动游戏。
2. 请打开游戏内的 MFG Unlock 面板，选择所需的最大倍率。您可以选择2x–6x，也可以选择 **跟随原生上限** 恢复原生上限。
3. 插件会在运行时应用新的上限，无需再次部署或重启游戏。您选择6x后，只要不再次修改，后续启动仍会使用6x。

您设置的数值是 Dynamic 最大倍率的上限，并非固定的生成倍率。NVIDIA 原生 Dynamic 会根据目标帧率、负载、硬件、驱动和运行库能力决定实际倍率，因此实际倍率不一定达到您设置的上限。此功能不能突破运行库和硬件本身的能力限制。

启动器不再提供部署时的静态倍率选项，旧的 DynamicMaxMultiplier 配置也不再限制运行时选择。新版插件通过 ReShade 保存游戏内选择；请确保 ReShade 配置文件可写，否则下次启动可能无法保留更改。

## 独立组件与升级

倍率控制由独立的 `wuwa-dynamicmax.addon64` 提供，`renodx-mfgunlock.addon64` 基于上游 1.1.5，集成中文菜单和界面桥接。开启多帧生成部署时，启动器会安装这两个组件。以后替换上游 MFG 插件时，无需重新合并倍率控制源码；完整退出游戏并重新部署后即可使用新插件。

游戏内的 **MFG Unlock** 面板提供独立开关和倍率选择。关闭这个开关后，控制器不再额外限制原生 Dynamic 的倍率。它只控制原生 Dynamic 模式，不修改 Fixed 倍率，也不跟随主插件的私有开关状态。

首次使用独立组件时，控制器会读取并迁移已有的倍率选择。配置保存在 ReShade 的 `[WuWa.DynamicMax]` 节中；后续部署不会重置它。请勿在游戏运行中删除或替换插件文件。

## 兼容性

运行时调整仍为实验性功能，仅支持随包适配的 Streamline 运行库。插件会检查运行库版本、线程和权限；检查失败时不会启用运行时调整。此功能使用针对指定版本的进程内适配，并非 NVIDIA 公开的上限设置接口。

第三方插件可能造成兼容性问题、崩溃或账号风险。请勿关闭安全软件或绕过系统权限来强行启用功能。

隔离测试已覆盖配置保存与读取逻辑，但不能代替游戏实测。本次修改后的跨游戏重启保存效果仍需在实际 ReShade 环境中验收。


## 分别关闭普通帧生成与 Dynamic

普通帧生成倍率和 Dynamic 最大倍率均提供 **关闭** 选项。两项选择独立保存：普通帧生成的关闭仅作用于普通模式，Dynamic 的关闭仅作用于 Dynamic 模式，不会改写另一项设置。在当前模式中选择关闭后，控制器请求仅输出原生渲染帧；恢复时，选择该模式所需的倍率即可。关闭“启用 Dynamic 最大倍率限制”表示停止干预 Dynamic，并不等于关闭帧生成。

更新前选择的“原生上限”会继续保留，不会因选项调整变为关闭。所有运行时控制均需通过组件兼容性检查。
