# Dynamic 运行时最大倍率

在游戏内 ReShade 的 **MFG Unlock** 面板调整 **Experimental live Dynamic maximum**。控制器默认请求 **4x**，初始化成功后作用于后续帧，无需为每次倍率调整重新部署或重启。

启动器不再提供静态倍率设置，旧的 DynamicMaxMultiplier 配置不再用于限制倍率。由旧版本升级时，必须退出游戏、重新部署并完整启动一次，以卸载旧插件和清除旧进程中的缓存。

## 使用

1. 退出游戏，使用新版启动器重新部署多帧生成组件，再启动游戏。
2. 打开 MFG Unlock，查看运行时控制是否就绪。插件会在匹配的运行库加载后尝试初始化；失败时显示原因，可使用面板重试入口。
3. 依次选择2x、3x、4x、5x、6x，观察实际生成倍率。Native bound (restore) 表示不额外收紧原生上限。
4. 热调整只作用于本次运行；下次启动恢复默认4x。

选择的是上限，不是强制倍率。实际倍率仍由 NVIDIA 原生 Dynamic 根据目标帧率、负载、硬件和驱动能力决定。5x/6x不再受本工具的启动4x配置限制，但不能突破运行时本身的原生上限。Last frame记录参数提交，不是实际生成倍率测量；排队中的旧帧可能稍后才消退。

## 兼容性

运行时控制是实验功能，仅适配随包指定的Streamline二进制与关键代码。匹配失败、线程或权限检查失败时停用热控制，不能把默认4x当作已生效。它使用版本限定的进程内适配，并非NVIDIA公开的上限设置接口。可能存在兼容性、崩溃和账号风险，不应关闭安全软件或绕过权限强行启用。

代码及隔离测试通过不代表游戏内验收通过。请分别观察控制状态、参数提交与实际倍率，并记录不同负载场景中的稳定性。
