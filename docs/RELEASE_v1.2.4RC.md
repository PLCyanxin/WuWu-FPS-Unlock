# 鸣潮 FPS Unlock v1.2.4RC

本次更新新增可自定义的菜单按键，统一帧生成关闭选项，并改善部署、一键清除和软件更新的可靠性。

> [!WARNING]
> **使用本工具有被官方封号的风险。使用工具后录制视频或分享截图等，请遮挡 UID，请勿跳脸官方。**（维护者实测可以正常与他人联机；能正常联机不代表没有封号风险。）

> [!IMPORTANT]
> **仅适用于 NVIDIA GeForce RTX 40 系列显卡和鸣潮官方启动器版本，未来不扩大支持范围。** 本版标记为 **Pre-release**，请在本页手动下载；维护者验证稳定后，会将其设置为 Release，供启动器检查和更新。

## Bug 修复与改进

- **自定义菜单按键：** 首次使用默认 Home，可录入单键或组合键；点击 **×** 可清空当前按键并显示“未设置”，停用游戏内菜单快捷键。需要恢复 Home 时，在按键框中重新录入 Home。显卡名称和驱动版本合并显示。
- **统一关闭帧生成：** 在“帧生成模式”中选择“关闭”，无需分别操作 Fixed 和 Dynamic 倍率菜单。切回其他模式时保留原先的倍率，升级也会保留已有的关闭状态。
- **改善游戏更新后的部署：** 官方更新改变运行库位置时，可在完成官方文件修复后，核对并重建本工具的路径记录，避免旧位置持续阻止部署。旧记录会保留，重建不会复制或删除游戏文件。
- **修复一键清除失败：** 已有完整部署记录时，即使原部署材料缺失，仍可清除已登记且未被修改的组件。清除前检查全部相关路径和配置；无法安全处理的文件会保留并提示。
- **改善 ReShade 配置兼容性：** 正确保留含逗号的路径及其他插件条目，识别实际使用的全局配置。重新部署会保留已保存的帧生成模式和倍率；配置有歧义时停止自动修改。
- **增强更新与回退恢复：** 更新意外中断后，可通过重新运行更新包或备份中的“恢复.cmd”恢复未完成的操作。回退期间再次检查游戏运行状态；成功更新后保留本机实际更新前的备份，并清理可确认的旧缓存。
- **改善启动与设置反馈：** 游戏启动失败时保留启动器和错误提示；关闭帧率解锁后，无效的 FPS 输入不再阻止普通启动。设置保存失败时显示实际结果，包体记录读取异常不阻止其他启动检测。
- **增强组件检查：** 拒绝空文件、截断文件及错误架构的部署材料；发现已部署组件缺失或被修改时，启动前给出处理提示。“帧生成模式”中的“关闭”仅在对应控制能力可用时允许选择。
- **改善托盘唤醒：** 唤醒通道暂时异常时自动重试，并提供提示，仍可通过托盘打开已有窗口。

## 使用方法

### 首次安装

下载 **WuWaFPSUnlock-1.2.4RC-win-x64.zip**，完整解压到固定目录，再运行 **WuWaFpsUnlock.exe**。保留随包的 `payload`、`components`、`licenses` 等目录；请将本工具放在鸣潮游戏目录之外。

先通过官方启动器完成游戏更新及所需包体下载。在本工具设置中选择鸣潮，再在主页选择对应包体档位。仅使用帧率解锁无需部署多帧生成组件；使用多帧生成时，请先退出游戏，在设置中点击 **开始部署**，核对计划并确认，之后通过本工具以 DX12 启动游戏。

### 更新已有安装

1. 正常退出游戏，并从托盘退出启动器。
2. 下载 **WuWaFPSUnlock-1.2.4RC-update.zip**，将解压后的整个独立更新文件夹放入原启动器目录，保持内部结构完整。
3. 运行其中的 **更新.exe**。不要单独移动更新器，也不要运行 `update-payload` 内的程序。
4. **更新期间请勿关闭更新窗口与游戏启动器，也不要启动游戏。**
5. 更新完成后，启动器会打开设置并提示 **“更新完成，请点击重新部署”**。请点击 **开始部署**，完成后再启动游戏。

更新包需要已有完整安装，不能代替首次安装包。更新成功后可以删除更新文件夹；请保留安装目录中的最新备份。如果更新被中断，请保持游戏和启动器关闭，重新运行同一更新包，或按提示运行备份中的 **恢复.cmd**；文件被其他程序改动或备份损坏时，更新器会停止恢复并保留记录。

如需回退，在设置中点击 **回退版本**，或运行备份目录中的 `rollback.cmd`。回退恢复更新前本机实际使用的程序与组件，保留当前配置和部署记录。**回退后同样需要重新部署。**

### 游戏内设置

按 **Home**（或自定义菜单按键）打开 ReShade，进入 **MFG Unlock**，选择 Dynamic、固定倍率（Fixed）、游戏默认或关闭，再调整对应选项。模式与倍率会自动保存，选择关闭不会清空已保存的倍率。

设置中的 **菜单按键** 支持单键或组合键录入。首次使用默认为 **Home**；右侧 **×** 会清空当前按键并显示“未设置”，对应 ReShade 配置 `KeyOverlay=0,0,0,0`，此时游戏内菜单快捷键停用。需要恢复 Home 时请点击按键框并重新录入 Home。修改会在重新部署或下一次启动游戏时应用。

**Dynamic 最大倍率仍为实验性功能。** 所选倍率是允许使用的上限，实际倍率由 NVIDIA 根据负载、硬件、驱动和运行库能力决定，不保证达到所选值。运行库兼容性检查未通过时不会启用热控制。

完整功能及使用说明见 [项目主页](https://github.com/PLCyanxin/WuWu-FPS-Unlock)。
